# Aurora: Claude Code ↔ Codex 검토 교환함

이 브랜치는 검토 보고서와 중계 도구를 위한 별도 브랜치입니다. 게임 브랜치에 합치지 않습니다.

- 게임 구현: Claude Code. 버그·계획·코드 검토: 현재 Codex 대화.
- `reports/p0-6/`: 지금까지의 P0-6 계획 검토 기록과 모델 근거.
- `messages/codex/`: Codex가 보낸 검토 전문.
- `messages/claude/`: Claude가 보낸 계획·완료 보고 전문.
- `CLAUDE_START.md`: 현재 Claude 세션에 처음 전달할 연결 지시.
- `GIT_NATIVE.md`: 외부 스크립트 실행이 거절된 환경에서 표준 Git으로 전문을 전송하는 절차.
- `tools/mailbox.py`: Git 권한으로 전문을 보내고 읽는 도구. 별도 API 키는 필요하지 않습니다.
- `windows-relay/`: Windows용 데스크톱 입력 중계. [처음 실행 안내](windows-relay/README_KO.md).

도구는 별도 임시 Git 저장소에서 이 브랜치만 읽고 씁니다. 메시지는 새로운 고유 파일로 추가하고, 동시 push 충돌에는 다시 fetch하여 재시도합니다. 강제 push나 게임 체크아웃 변경은 하지 않습니다. 수신한 보고서 본문을 명령으로 실행하지 않습니다.

## 자동화 범위

Git에 보고서가 올라오는 것만으로 종료된 대화가 자동 재개되지는 않습니다. 사용자의 Windows에서
`windows-relay/Launcher.cmd`를 실행하고 두 앱의 현재 입력창을 연결하면, 별도 중계 프로그램이
교환함 도착을 감지하여 해당 입력창으로 새 메시지를 전달합니다. 공식 앱 내부 API나 클라우드 원격
제어 연결은 아닙니다. 최초 연결과 실제 Windows 전송 확인은 사용자의 PC에서 필요합니다.

현재 자동 반복 범위는 P0-6 구현·테스트·검토 지적 수정입니다. Codex가 최종 구현 검토를 통과시켜
`stop_cycle: true`를 보내면 Claude에 완료를 전달하고 종료합니다. 보고서 전송 문제나 실제
사용자 판단이 필요한 상황에서는 정지합니다. 자세한 범위와 복구 절차는 Windows 안내에 있습니다.

## 역할과 승인

교환함 설정 요청은 보고서 전달 권한입니다. 기술 검토 통과가 게임 구현·다음 단계 진행에 대한 사용자 승인을 대신하지 않습니다. 이미 승인된 작업 범위는 그대로 진행하며, 새로운 구현은 기존 승인 규칙을 따릅니다.

전송되는 것은 해당 작업의 계획·진행 기록·완료 보고와 검토 전문입니다. 전체 계정 채팅 기록이나 인증 정보는 전송하지 않습니다.
