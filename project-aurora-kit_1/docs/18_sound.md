# 사운드

소리의 목표는 ‘무게감’이다. 무거운 금속·기계는 저음을 두텁게, 마력은 맑은 고음 울림으로 구분한다. 같은 소리가 반복돼도 티 나지 않게 파일마다 변형 3\~5개를 두고 높낮이를 ±5% 무작위로 바꾼다.

## 재생 규칙

- **3D 위치**: 거리마다 작아지고, 멀수록 고음이 깎인다(포성은 500블록까지 들림).
- **공간 울림**: 동굴·던전·큰 실내는 잔향을 자동 적용.
- **우선순위**: 동시에 나는 소리가 64개를 넘으면 멀고 중요도 낮은 것부터 생략.
- **볼륨 채널**: 마스터, 음악, 효과음, 환경음, 주민 목소리, UI.

## 주민 목소리

실제 언어 대신 알아들을 수 없는 가상의 말(중얼거림)과 짧은 감탄사를 쓴다. 남·여·아이 각 3명분의 목소리, 감정 5가지(기쁨·불만·놀람·고통·인사). 병사는 구호·돌격 함성이 따로 있다.

## 음악

편성은 오케스트라 + 파이프오르간 + 남성 합창 + 금속 타악기(모루·체인). 고딕 산업 분위기를 내되, 평화로운 곡은 조용하고 여백이 많게. 상황이 바뀌면 박자에 맞춰 자연스럽게 넘어간다.

| 트랙 | 쓰는 상황 | 분위기 |
| --- | --- | --- |
| 메인 테마 | 타이틀 | 장엄하고 느린 오르간 + 합창 |
| 개척 (3곡) | 초반 낮 | 피아노·현악, 쓸쓸하지만 따뜻하게 |
| 번영 (3곡) | 중반 이후 낮, 도시 안 | 금관 추가, 힘차게 |
| 밤 (2곡) | 밤 | 낮은 현악, 긴장감 |
| 마력 숲·결정 평원 | 해당 바이옴 | 유리종·신비로움 |
| 전투 (소규모 / 대규모) | 교전 시 | 타악기 중심 / 풀 오케스트라 |
| 던전 | 던전 안 | 어둡고 느린 저음 |
| 보스 (7곡) | 보스별 | 보스마다 다른 주제 선율, 단계에 따라 격해짐 |
| 아시리아 테마 | 아시리아 영토·원정군 | 청동 금관 + 고대 음계 |
| 승리 | 아시리아 승리 | 메인 테마의 장조 변주 |

## 제작 방법

- 개발 초기: 절차 생성 효과음 + CC0 무료 소리로 자리를 채운다.
- 후반(P6): 음악과 핵심 효과음(총성·폭발·보스)은 사람 작곡가·사운드 디자이너에게 맡기는 것을 권장한다. 내가 만드는 소리는 품질에 한계가 있다.
- 파일: OGG, 48kHz. 효과음은 모노(3D 배치용), 음악·UI는 스테레오.
