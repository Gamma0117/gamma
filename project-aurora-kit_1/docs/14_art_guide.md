# 아트 가이드

게임은 3D다. 마인크래프트처럼 블록으로 이루어진 세계와 상자 모델을 쓰되, 텍스처는 1블록 = 32픽셀로 명암·하이라이트·질감을 분명하게 넣는다. 평평하게 칠한 옛날 도트 느낌은 피한다. 색·재질·디자인은 모두 새로 만들고, 마인크래프트 텍스처·모델을 복사하거나 본뜨지 않는다.

## 핵심 규칙

1. **텍셀 밀도 통일**: 1블록 = 32픽셀, 모델 1단위(1/16블록) = 2픽셀. 블록·아이템·생물·탈것 모두 같다. 큰 모델도 픽셀이 커지지 않고 늘어난 만큼 텍스처가 커진다.
2. **음영은 높이맵에서**: 모든 텍스처는 높이맵을 먼저 만들고, 거기서 명암·틈새 그늘(AO)·노멀 맵을 뽑는다. 금속·광물·유리는 반사 하이라이트를 따로 넣는다.
3. **재질당 6\~8단계 색, 색상 이동**: 어두운 쪽은 푸르거나 보랏빛으로, 밝은 쪽은 따뜻하게 옮겨 칙칙하지 않게 한다.
4. **검은색 쓰지 않기**: 블록 텍스처의 가장 어두운 색도 밝기 약 25%(돌 기준 #46454d) 아래로 내리지 않는다. 조약돌·돌벽돌의 줄눈과 틈은 검정이 아니라 어두운 회색. 원래 검은 재질(석탄, 흑철, 심층암)만 예외로 한 단계 더 어둡게 허용한다.
5. **광물은 돌 3 : 광물 1**: 광석 블록은 면적의 약 25%가 광물이다. 광물 알갱이는 서로 1픽셀 이상 떨어뜨리고, 둘레에 어두운 테두리와 윗면 하이라이트를 넣어 하나하나 구분되게 한다.
6. **빛은 왼쪽 위에서**: 텍스처에 굽는 음영은 왼쪽 위 기준. 실제 조명·그림자는 쉐이더가 노멀 맵으로 더한다.
7. **외곽은 딱 떨어지게**: 아이템 실루엣과 알파는 0 또는 255만 쓰고, 안쪽 음영은 부드러워도 된다. 확대는 최근접 필터.
8. **타일링 검사**: 블록 텍스처는 3×3으로 이어 붙였을 때 이음새·반복 무늬가 티 나지 않아야 한다.
9. **실루엣 우선**: 아이템 아이콘은 1픽셀 외곽선을 두되, 순검정 대신 재질 색이 섞인 짙은 회색(#262a33 안팎)을 쓴다.
10. **아이템 방향**: 칼·도구·배터리 같은 긴 아이템은 왼쪽 아래에서 오른쪽 위로 향하는 대각선으로 그린다.

### 3D 무기 모델·재질 (계획, 아직 만들지 않음)

지금 샘플의 3D 무기는 단색 재질을 입힌 상자라 플라스틱처럼 보인다. 실제 제작 때는 아래 기준으로 만든다.

| 항목 | 기준 |
| --- | --- |
| 모양 | 칼날은 가운데 능선이 있는 마름모 단면, 끝으로 갈수록 폭과 두께가 줄어든다. 날(엣지)은 얇게 따로 깎고 홈(풀러)은 오목하게 판다. 가드·폼멜은 모서리를 깎은(베벨) 형태, 손잡이는 가죽이 감긴 나선 홈 |
| 텍스처 밀도 | 다른 모델과 같이 1단위 = 2픽셀. 무기마다 UV 아틀라스 한 장에 색·거칠기·금속성·노멀·발광을 둔다 |
| 금속 표면 | 날 가장자리는 갈아낸 듯 밝고 매끄럽게, 풀러 안쪽은 어둡고 거칠게, 면 전체에 가는 긁힘(거칠기 변화). 가드는 모서리만 닳아 밝고 오목한 곳엔 때가 낀다 |
| 반사 | 반사 프로브(주변 큐브맵)와 프레넬을 쓴다. 밝은 곳에서는 하늘이, 동굴에서는 주변 색이 비친다. 하이라이트는 좁고 강하게 해서 플라스틱의 넓고 흐릿한 광택을 피한다 |
| 가죽·나무 | 거칠기 0.75\~0.9, 노멀로 결과 감긴 자국을 살린다 |
| 발광(룬) | 따로 붙인 상자가 아니라 발광 맵에 새긴다. 평소엔 은은하고, 휘두를 때만 조금 밝아진다. 블룸은 약하게 |
| 색 | 채도를 낮추고 금속 색은 반사로 표현한다. 오로라 합금은 푸른 강철에 옅은 청록 광택, 금색은 가드 끝·폼멜 같은 작은 포인트에만 쓴다 |
| 1인칭 | 화면 가까이 보이므로 1인칭 전용으로 조금 더 촘촘한 모델을 쓴다 |
| 제작·검수 | Blockbench에서 상자와 메시로 만들고, 텍스처는 생성 스크립트로 초안을 낸 뒤 손으로 다듬는다. 햇빛·동굴·흰 배경 세 가지 조명에서 플라스틱처럼 보이지 않는지 확인한다 |

- **보간**: 키와 키 사이는 속도가 이어지는 곡선(비균일 Catmull-Rom, 장력 0.85)으로 잇는다. 키마다 멈추지 않으므로 동작이 각지지 않는다. 빠르기는 키 간격으로 정한다. 도구 휘두르기처럼 한 번씩 딱 끊겨야 하는 동작만 구간별 이징(ease-out·ease-in·back)을 쓴다.
- **추가 흔들림**: 망토·사슬·장식은 스프링 물리(단단함 0.3, 감쇠 0.8)로 따라온다. 머리는 시선을 최대 70도까지 따라간다. 경사진 곳에서는 발이 땅에 맞춰진다.
- **1인칭 손**: 마우스를 돌리면 무기가 0.1초 늦게 따라오고, 걸음과 맞춰 흔들리며, 반동 후 0.15초에 복귀한다.
- **타격감**: 히트스톱 일반 0.05초, 강타·패링 0.10초(60fps 기준 3·6프레임). 멈춘 동안 공격자와 맞은 쪽이 함께 멈추고, 파티클·화면 흔들림은 계속 움직인다. 화면 흔들림 0.3도 / 1도. 설정에서 끌 수 있다.

### 쫀득한 동작 원칙 (Actions & Stuff 참고)

- **흐름**: 앞 동작의 마무리가 다음 동작의 준비가 되게 잇는다(1타 휩쓴 힘으로 2타 준비, 2타 올려벤 기세로 3타 회전).
- **늘어남·찌그러짐**: 도약·착지·강타에서 몸 세로 배율 0.8\~1.12, 가로는 1/√세로로 부피를 유지한다.
- **한 박자 늦게 따라오기**: 머리·반대 팔·장식은 스프링(감쇠비 0.3 안팎)으로 몸통을 늦게 따라오고, 멈추면 두세 번 흔들리다 선다.
- **몸통 비틀기**: 걸을 때 골반과 어깨가 반대로 돌고, 휘두를 때는 팔보다 몸통이 먼저 돈다.
- **발은 땅에 붙인다**: 걸을 때 딛는 다리 각도에서 골반 높이를 역산해 발이 뜨거나 파묻히지 않게 한다.
- **1인칭 손**: 휘두를 때마다 들어올림·내리찍기·반동이 있고, 가만히 있어도 숨쉬듯 흔들린다.
- **칼날 방향**: 검은 매 프레임 칼끝이 움직이는 방향을 계산해서, 칼날의 날 쪽이 그 방향을 향하도록 칼을 자기 축으로 돌린다(스프링으로 부드럽게). 칼 옆면으로 휘두르는 어색함을 막는다.
- **이펙트 절제**: 타격 이펙트는 불꽃·파편·짧은 궤적까지만 쓴다. 바닥에 퍼지는 고리 같은 큰 이펙트는 쓰지 않는다.
- **점프는 단순하게**: 점프·착지는 무릎을 살짝 굽혔다 펴는 정도로만 하고, 팔 휘두르기나 큰 찌그러짐은 넣지 않는다.
- **1인칭 도구**: 도구는 팔에 고정된 것처럼 보이면 안 된다. 손목이 팔보다 조금 늦게, 더 크게 움직여 도구 머리가 큰 호를 그린다.

## 파티클·효과

타격 불꽃, 체액(사람 붉은색, 몬스터는 녹색·보라, 설정에서 끄기 가능), 먼지, 블록 파편(부서진 블록 텍스처에서 색을 따옴), 연기, 마력 입자(청록 발광), 폭발 섬광, 충격파(화면 왜곡 쉐이더).

## UI

- 금속 질감 패널 + 9칸 늘리기 방식 테두리, 리벳 장식 모서리. 패널도 32px 텍스처와 같은 음영 규칙을 쓴다.
- 한글 폰트는 OFL 라이선스 폰트 사용(본문은 가독성 좋은 고딕, 제목은 장식 서체. 최종 라이선스 확인 후).

## 쉐이더 색감

햇빛은 따뜻한 호박색, 그림자는 차가운 청회색. 마력 발광은 블룸으로만 강조하고, 낮에는 약하게 밤에는 강하게 보인다. 전체적으로 채도를 약간 낮춰 고딕 산업 분위기를 낸다.

## 제작 절차 (내가 만드는 방식)

1. 위 팔레트·규칙을 넣은 생성 스크립트로 텍스처 초안 PNG를 만든다.
2. 한 장에 모아 보는 검수 시트를 만들어 피드백을 받는다.
3. 모델·애니메이션은 Blockbench에서 열 수 있는 형식으로 만들어, 나중에 사람이 직접 고칠 수 있게 한다.
4. 게임 안 스크린샷으로 확인하고 다듬는다.

## 아트 샘플 (3차, 32px · 3D)

3차 피드백 반영: 텍스처 32×32, 검은색 줄임(조약돌·돌벽돌 줄눈은 어두운 회색), 광석은 돌 3 : 광물 1이고 알갱이가 하나하나 구분됨, 배터리는 대각선에 명암·하이라이트·질감, 오로라 검은 단정하게, 플레이어 머리 7단위로 축소. 동작은 키 사이를 곡선으로 이어 부드럽게, 칼날이 휘두르는 방향을 향함, 3타 바닥 고리 이펙트 삭제, 점프는 최소 동작, 1인칭 곡괭이는 손목이 크게 움직임.
