# 상세 목록

기획서 본문을 뒷받침하는 데이터 초안이다. 모든 수치는 본문 24장(밸런스)을 기준으로 잡았고, 피드백을 받아 고친다. 하위 탭에 분야별 목록이 있다.

- 1\. 블록·아이템·제작법 — 자연·건축·기능 블록, 재료, 도구, 식품, 핵심 제작법
- 2\. 건물 목록 — 생활·생산·행정·군사 건물과 비용·해금 조건
- 3\. 기술 트리 — 7개 분야 75개 노드, 선행·비용
- 4\. 무기·갑옷·탈것 — 근접·원거리·폭발 무기, 갑옷, 탈것 20종
- 5\. 몬스터·던전 — 몬스터 18종, 보스 7종, 둥지, 던전 6종
- 6\. AI 제국 — 아시리아·아틀란·타지리 포함 고정 AI 세력 6개와 소왕국

* 7\. 주민·직업·성향·행복도 — 직업별 생산량, 성향 16종, 소비량, 행복도 계산
* 8\. 생산 체인·경제 수치 — 식량 균형, 체인 예시, 연구 속도, 가격, 세금, 영토 비용
* 9\. 법령·외교 — 기본 정책, 법령 18종, 관계도, 협정, 전쟁 점수
* 10\. 군사 상세 — 편제, 병사 성장, 진형, 사기, 보급, 장군 특성, 전투 예시
* 11\. 각인·주문 상세 — 각인 레벨·확률·효과, 특수 각인 10종, 주문 레벨, 의식
* 12\. 조작·UI — 키 배치, 전략 지도, 화면 구성
* 13\. 생태·시스템 수치 — 작물, 가축, 마력 오염, 날씨, 이벤트 확률, 경험치, 칭호, 저장

- 14\. 아트 가이드 — 해상도, 팔레트, 모델 비율, 애니메이션 목록, 제작 절차
- 15\. 데이터 파일 구조 — 폴더, ID, JSON 예시, 저장 파일
- 16\. 보스 패턴 — 보스 8종 단계별 기술·예고·대처
- 17\. 탈것 부품·전차 — 차체·엔진·무장·모듈, 부위 피해, 전차 6종, 조립 예시

- 19\. 설정·접근성 — 그래픽·오디오·조작·게임플레이·접근성 옵션
