# 군사 상세

병사·부대·장군·사기·보급의 세부 규칙이다. 피해 공식은 본문 24장을 따른다.

## 편제

| 단위 | 인원 | 지휘관 | 비고 |
| --- | --- | --- | --- |
| 분대 | 8 | 분대장 (병사 레벨 5 이상) | 한 병종으로 구성 |
| 소대 | 32 (분대 4) | 소대장 (레벨 10 이상) | 병종 혼합 가능 |
| 중대 | 128 (소대 4) | 중대장 (군사학 학사 권장) | 전략 지도에서 한 아이콘 |
| 대대 | 512 (중대 4) | 장군 | 장군이 있어야 편성 가능 |

탈것은 승무원을 병사로 채운다: 트럭 1, 장갑차 3, 전차 4, 철관 보행기 1, 전투기 1, 폭격기 4, 구축함 40, 전함 120, 비행 전함 150.

## 병사 성장

- 레벨 1\~20. 경험치는 전투(처치 등급별 5\~50), 훈련장(하루 10), 생존한 전투마다 20.
- 레벨당 체력 +0.5(최대 30), 명중 +1%, 사기 +1.
- 레벨 5·10·15·20에서 병종 특기 1개를 얻는다 (예: 소총병 ‘조준 사격’ 치명타 +10%, 공병 ‘속성 참호’ 건설 속도 +50%).
- 병사가 제대하면 주민으로 돌아가고 레벨은 유지된다.

## 진형

| 진형 | 장점 | 단점 | 조건 |
| --- | --- | --- | --- |
| 횡대 | 사격 +20% | 측면 피격 피해 +25% | — |
| 종대 | 이동 +30% | 방어 −20% | — |
| 방진 | 근접 방어 +20%, 돌격 무력화 | 이동 −40% | TAC-1 |
| 산개 | 폭발 피해 −25% | 근접 −15%, 사기 회복 느림 | TAC-3 |
| 쐐기 | 돌격 첫 타격 +25% | 돌격 후 방어 −10% (5초) | TAC-2 |
| 엄폐 | 엄폐물 뒤 피해 −40% | 이동 불가 | — |

## 사기

부대별 0\~100. 시작값 70 + 장군·특성 보너스.

| 사건 | 변화 |
| --- | --- |
| 아군 전사 | 1명당 −2 |
| 포격·폭격 피격 | 한 발당 −1 |
| 측면·후방 공격받음 | −10 |
| 장군 전사 | −30 |
| 적 부대 패주시킴 | +10 |
| 장군·왕이 근처에 있음 | 초당 +0.5 회복 |
| 보급 끊김 | 하루 −10 |

- 30 이하: 공격 −20%, 명령 무시 확률 10%
- 0: 패주 (가장 가까운 아군 거점으로 도망, 10초 뒤 재집결 시도)

## 보급

- 병사 1명은 하루 음식 12, 전투 1회에 탄약을 무기별로 소모한다 (소총병 약 20발).
- 병창·전초기지 반경 64블록 안은 자동 보급. 밖은 보급대(마차 → 트럭 → 수송기)가 실제로 오가야 한다.
- 보급이 끊기면 하루마다 사기 −10, 3일째부터 체력이 줄어든다. 탈것은 연료·배터리가 떨어지면 멈춘다.

## 장군

- 레벨 1\~30. 경험치는 지휘한 전투의 규모·승패로 얻는다. 레벨업마다 특성 포인트 1.
- 지휘 범위 = 24블록 + 레벨 × 1블록. 범위 안 부대만 특성 효과를 받는다.

| 특성 분류 | 특성 (I / II / III) | 효과 |
| --- | --- | --- |
| 지형 | 숲·산악·사막·설원·습지·해상·공중·지하 전문가 | 해당 지형에서 공격·방어 +10 / 20 / 30%, 이동 페널티 제거(II부터) |
| 병종 | 보병·기갑·포병·마도·항공·해군 전문가 | 해당 병종 피해·방어 +8 / 16 / 25% |
| 공통 | 당당한 지휘 | 사기 +5 / 10 / 20 |
| 공통 | 병참의 달인 | 보급 소모 −15 / 30 / 45% |
| 공통 | 끝까지 버틴다 | 패주 기준 사기 0 → −10 / −20 / −30 |
| 공통 | 질풍같이 | 지휘 부대 이동 +10 / 20 / 30% |
| 공통 | 의무 복지 | 부상병 사망 확률 −20 / 40 / 60% |

## 전투 예시 — 오우거 야영지 토벌

1. **편성**: 소총 분대 2 + 박격포 2문 + 공병 분대 1, 장군 ‘산악 전문가 II’. 장비는 마강(T3급), 야영지는 T3\~T4.
2. **접근**: 종대로 이동, 야영지 200블록 앞에서 공병이 참호를 판다.
3. **교전**: 박격포 공격으로 오우거 전사를 끌어내고, 소총 분대는 횡대·엄폐로 사격. 오우거 전사(체력 110)는 마강 소총(한 발 20) 기준 약 6발에 쓰러진다.
4. **보스**: 5단계 둥지면 오우거 족장(체력 980)이 나온다. 지면 강타에 대비해 산개 진형으로 바꾸고, 플레이어가 직접 근접전으로 마무리.
5. **결과**: 둥지 제거, 텅스텐·오우거 뼈 획득, 병사 경험치 +20\~50, 장군 경험치, 전투 경험치(CXP) +120.
