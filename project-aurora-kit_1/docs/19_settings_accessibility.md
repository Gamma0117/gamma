# 설정·접근성

모든 설정은 게임 중에 바로 바꿀 수 있고 `settings.json`에 저장된다. 난이도(일반·하드코어)만 월드를 만들 때 정하고 바꿀 수 없다.

## 그래픽

| 항목 | 선택지 |
| --- | --- |
| 프리셋 | 낮음 / 중간 / 높음 / 울트라 / 사용자 |
| 해상도·창 모드 | 전체화면 / 창 / 테두리 없는 창 |
| 프레임 제한·수직 동기 | 30 / 60 / 120 / 144 / 무제한, 켜기·끄기 |
| 렌더 거리 | 4\~32청크 |
| 시뮬레이션 거리 | 4\~16청크 (주민·생물이 움직이는 범위) |
| 그림자·SSAO·반사·블룸·볼륨 안개 | 각각 끄기\~높음 |
| 시야각 | 60\~110도 |
| 밝기(감마) | 슬라이더 |
| 멀리 있는 주민 표시 수 | 100\~2,000 |
| 파티클 양 | 최소 / 줄임 / 전부 |

## 오디오

마스터·음악·효과음·환경음·목소리·UI 채널별 음량, 출력 장치, 창이 비활성화되면 소리 줄이기.

## 조작

- 모든 키 변경, 초기화. 같은 키가 겹치면 빨간색 경고.
- 마우스 감도, Y축 반전, 조준 시 감도 따로.
- 누르고 있기 / 눌러서 켜기·끄기 전환: 달리기, 웅크리기, 조준, 지휘 휠.
- 게임패드는 후순위.

## 게임플레이

| 항목 | 선택지 |
| --- | --- |
| 자동 저장 간격 | 1\~15분 |
| 타격 멈춤(히트스톱) | 켜기 / 줄임 / 끄기 |
| 화면 흔들림 세기 | 0\~100% |
| 체액 효과 | 켜기 / 끄기 |
| 전략 지도 시간 배속 (싱글만) | ×0.25 / ×0.5 / ×1 |
| 알림 필터 | 정보·주의·위협별 켜기·끄기 |
| 목표 안내(튜토리얼) | 켜기 / 끄기 |
| 피해 숫자 표시 | 켜기 / 끄기 |

## 접근성

| 항목 | 내용 |
| --- | --- |
| 자막 | 주민·병사 대사와 주요 효과음을 글자로 표시 |
| 소리 방향 표시 | 화면 가장자리에 소리가 난 방향을 표시 (보스 예고음·포성·몬스터) |
| 색약 모드 | 적록(두 종류) / 청황. 위험 표시는 색과 함께 모양도 다르게(△ ○ □) |
| UI 크기 | 1\~4배, 글자 크기 따로 |
| 고대비 UI | 패널 배경을 더 어둡게, 테두리를 더 밝게 |
| 깜빡임 줄이기 | 폭발 섬광·낙뢰·마력 폭풍 번찍임을 약하게 |
| 화면 흔들림·멀미 방지 | 흔들림 0%, 걸을 때 카메라 흔들림 끄기, 시야각 고정 |
| 조준 보조 | 약한 자동 조준 (싱글 전용) |
| 한 손 조작 프리셋 | 주요 동작을 마우스 주변 키로 모음 |

## 언어

한국어(기본), 영어. 나머지는 번역 파일로 추가.
