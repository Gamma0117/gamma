# 법령·외교

법령은 왕국 등급별 슬롯(1\~6칸) 안에서 고르고, 세율·배급·노동 시간·징병·의무교육 5가지는 슬롯 없이 항상 정하는 기본 정책이다. 법령을 바꾸면 3일(90분) 동안 다시 바꿀 수 없다.

## 기본 정책 (슬롯 불필요)

| 정책 | 선택지 | 효과 |
| --- | --- | --- |
| 세율 | 낮음 / 보통 / 높음 / 수탈 | 세수 ×0.6 / 1.0 / 1.5 / 2.2, 행복도 +5 / 0 / −10 / −25 |
| 배급 | 균등 / 능력별 / 군·연구 우선 | 균등: 행복도 +3 · 능력별: 숙련도 7 이상 생산 +10%, 나머지 행복 −3 · 우선: 부족 시 병사·연구원 먼저 배급 |
| 노동 시간 | 짧게 / 보통 / 길게 | 생산 ×0.85 / 1.0 / 1.2, 행복도 +6 / 0 / −10 |
| 징병 | 모병제 / 징병제 10% / 20% / 총동원 40% | 징병제는 SOC-6, 총동원은 SOC-8 필요. 모병제는 지원자만(병사 1명 3동화/일), 징병률이 높을수록 행복도 −3 / −6 / −15 |
| 의무교육 | 없음 / 초등 / 중등 / 고등 / 학사 | 아이가 일을 시작하는 시점과 교육 수준이 정해진다 |

## 법령 (슬롯 사용)

| 분야 | 법령 | 효과 | 해금 |
| --- | --- | --- | --- |
| 경제 | 자유 시장 | 교역 이익 +25%, 사치품 가격 −20% | 작은마을 |
| 경제 | 마석 전매제 | 마석 판매 세수 +40%, 마석 교역량 −50% | 중간마을 |
| 경제 | 전시 경제 | 무기·탄약 생산 +30%, 생필품·사치품 −30% | 소국 |
| 노동 | 휴일제 | 5일마다 하루 휴식: 행복도 +8, 생산 −10% | 촌락 |
| 노동 | 야간 교대 | 조명 있는 시설은 밤에도 가동(생산 +30%), 해당 직원 행복 −5 | 중간마을 |
| 교육 | 장학 제도 | 학위 기간 −25%, 학생 1명당 1동화/일 | 중간마을 |
| 교육 | 연구 지원법 | 연구 +15%, 연구원 1명당 2동화/일 | 큰마을 |
| 군사 | 상비군 훈련령 | 병사 경험치 +50%, 훈련 중 병사는 노동 안 함 | 작은마을 |
| 군사 | 장교 양성 | 장군 경험치 +30%, 군사학 학위 기간 −30% | 큰마을 |
| 사회 | 이민 개방 | 이주민 도착 속도 ×2, 향수병 성향 확률 증가 | 촌락 |
| 사회 | 치안령 | 경비병 배치 범위 +50%, 치안 욕구 자동 충족 | 촌락 |
| 사회 | 국교 지정 | 신앙 욕구 충족 +50%, 신실함 없는 주민 행복 −2 | 작은마을 |
| 마력 | 마력 통제법 | 마력 오염 −30%, 마력 장치 효율 −10% | 중간마을 |
| 마력 | 마력 자유화 | 마력 장치 효율 +15%, 오염 +50%, 마도 신정 관계 −10 | 중간마을 |
| 마력 | 마도사 등록제 | 마도사 병종 징집 +50%, 마력 친화 주민 행복 −3 | 소국 |
| 제국 칙령 | 대원정령 | 10일간 전군 사기 +20, 이동 +10% (쿨다운 30일) | 대제국 |
| 제국 칙령 | 황금기 선포 | 10일간 행복도 +15, 금화 500 소모 | 대제국 |
| 제국 칙령 | 도량형 통일 | 모든 생산 +10% (영구) | 대제국 |

예시: 중간마을(법령 2칸)에서 ‘휴일제 + 장학 제도’를 고르면 행복도와 인재에 투자하는 내정형, ‘상비군 훈련령 + 야간 교대’를 고르면 전쟁 준비형 왕국이 된다.

## 외교 관계도

관계도는 −100\~+100이며 매일 조금씩 0으로 돌아간다(하루 ±1).

| 구간 | 상태 | 가능한 행동 |
| --- | --- | --- |
| +60 \~ +100 | 우리 | 동맹, 기술 교류, 혼인 동맹 |
| +20 \~ +59 | 우호 | 교역 협정, 통행권, 불가침 |
| −9 \~ +19 | 중립 | 교역, 선물, 불가침 |
| −49 \~ −10 | 냉담 | 교역 제한, 조공 요구를 받을 수 있음 |
| −100 \~ −50 | 적대 | 선전포고 가능성, 국경 봉쇄 |

| 요인 | 변화 |
| --- | --- |
| 교역 협정 유지 | 하루 +1 (최대 +30까지) |
| 선물 | 금화 10당 +5 (하루 최대 +20) |
| 같은 적과 전쟁 중 | +20 |
| 조공 요구 수락 / 거절 | +15 / −20 |
| 영토 침범 | −5 (회당) |
| 상단 약탈 | −30 |
| 선전포고 | −60 (다른 제국들도 −10) |
| 도시 파괴 | 전 제국 −15 |
| 성향 차이 | 마도 신정: 플레이어 영토 오염 50 이상이면 하루 −1 · 아틀란: 왕국 등급이 낮으면 무시 |

## 협정 종류

| 협정 | 내용 | 조건 |
| --- | --- | --- |
| 교역 협정 | 상단 왕래, 관세 −50% | 우호 |
| 불가침 | 10일간 서로 공격 불가, 깨면 전 제국 −30 | 중립 이상 |
| 통행권 | 군대가 상대 영토 통과 가능 | 우호 |
| 기술 교류 | 상대가 가진 노드 하나를 비용 −50%로 연구 | 우리 |
| 방어 동맹 / 공격 동맹 | 공격받으면 참전 / 함께 선전포고 | 우리 |
| 조공 | 매일 금화·자원 지급 | 상대가 약하거나 전쟁에서 패배 |
| 속국화 | 세수 20% + 병력 제공, 외교권 박탈 | 수도 점령 또는 압도적 전쟁 점수 |

## 전쟁과 평화

- **전쟁 점수** (0\~100): 전투 승리 +2\~10, 도시 점령 +15, 상단·창고 약탈 +3, 상대 왕좌 점령 +50. 평화 협상에서 점수를 조건에 쓴다.
- **평화 조건과 비용**: 배상금(점수 1당 금화 5), 도시·영토 할양(도시 1개 25점), 조공 약속(20점), 속국화(60점), 합병(왕좌 점령 후에만).
- **전쟁 피로**: 10일째부터 하루 행복도 −1 (최대 −20). AI도 같은 규칙이라 오래 버티면 상대가 평화를 제안한다.

예시: 타지리 왕국과 전쟁해 유전 도시 1곳을 점령하고 전투 3번을 이기면 약 35점. 도시 할양(25점) + 배상금 50금화(10점)로 평화를 맺으면 석유 공급지를 얻는다.
