# 애니메이션 목록

게임에 들어가는 모든 움직임의 계획이다. 길이는 초 단위, ‘흐름’은 주요 자세가 이어지는 순서, ‘효과’는 그 타이밍에 붙는 소리·파티클·카메라다. 모델 구조와 기본 동작 규칙은 아트 가이드 탭을 따른다.

## 원칙

1. **키프레임 + 절차 레이어**: 손으로 만든 키프레임 위에 호흡·발 IK(경사에 발 맞춤)·시선 따라가기·망토 흔들림을 코드로 겹친다.
2. **상체·하체 분리**: 달리면서 재장전, 걸으면서 주문처럼 두 동작을 동시에 재생한다.
3. **자연스러운 전환**: 동작이 바뀔 때 0.1\~0.2초 섞어서 넘어간다. 공격은 앞부분을 짧게 섞어 반응이 느리지 않게.
4. **예비→동작→회복**: 모든 공격·작업 동작은 준비 자세(무게 실기), 타격 순간(가장 빠름), 되돌아오기(관성)의 3단계로 만든다. 이것이 ‘무게감’의 핵심이다.
5. **이벤트 트랙**: 소리·파티클·피해 판정은 키프레임에 붙여 정확한 순간에 나온다.
6. **거리별 간소화**: 32블록 밖은 초당 10번만 갱신, 64블록 밖은 반복 동작만, 128블록 밖은 고정 자세. 주민 수백 명을 감당하기 위함.
7. **1인칭과 3인칭은 따로**: 플레이어 시점에서 보이는 손·무기는 별도 애니메이션으로 더 크고 역동적으로 만든다.

## 근접 전투

모든 무기에 공통: 막기(0.15, 유지 시 반복), 패링 성공(0.3, 불꽃 + 상대 비틀거림), 가드 붕괴(0.8, 무기가 튀어 올라가고 무방비), 구르기(0.5), 백스텝(0.3), 실패한 휘두름(허공에서 관성으로 몸이 늘어짐).

| 무기 | 콤보 | 차지 공격 | 특징 |
| --- | --- | --- | --- |
| 검 | 3타: 가로 → 대각 → 내리찍기 (0.35 / 0.40 / 0.55) | 준비 0.6 → 돌진 찌르기 | 가장 빠름, 3타에 몸 회전 |
| 도끼 | 2타: 대각 내리치기 → 반대 대각 (0.5 / 0.6) | 어깨 넘어 내리찍기 | 방패 가드 붕괴 |
| 창 | 3타: 찌르기 ×2 → 휘둘러 쓸기 (0.3 / 0.3 / 0.6) | 긴 준비 후 강하게 찌르기 | 사거리가 길어 팔을 쭉 뻗음 |
| 대검 | 2타: 가로 횡베기 → 회전 베기 (0.8 / 1.0) | 하늘로 들어 내리찍기 (충격파) | 무거워서 들 때 몸이 뒤로 제쳐짐 |

| 톱날검 | 누르고 있으면 갖다 대고 갈기 (반복 0.2) | 시동 후 내리치기 | 톱날 회전, 불꽃·체액 튀김, 모터 소리 |

## 주민 작업

직업마다 ‘작업 루프’가 있다: 작업 동작을 몇 번 반복하고, 결과물을 나르고, 가끔 쉬는 동작을 섞는다. 행복도가 낮으면 쉬는 동작이 자주 나오고 동작이 느려진다. 허리를 펴고 어깨를 돌리는 ‘기지개’(1.2)는 모든 직업 공통.

## 몬스터

모든 몬스터는 서 있기·이동·공격·피격·쓰러짐 5가지를 기본으로 갖고, 공격에는 반드시 예고 동작이 있다. 보스는 보스 패턴 탭의 기술마다 예고 + 공격 + 회복 동작을 따로 만든다.
