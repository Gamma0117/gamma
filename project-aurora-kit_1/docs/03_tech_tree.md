# 기술 트리

7개 분야 77개 노드 초안이다. 비용은 연구점(RP) 기준이고, 플레이어는 같은 값의 분야 포인트(공학·산업·마력학)로 대신 지불할 수 있다. 전략·전술은 전투 경험치(CXP)로만 연구한다.

- **시대별 비용 범위**: 중세 50\~300 · 증기 400\~1,500 · 산업 2,000\~8,000 · 근대 10,000\~80,000
- **시대 전환**: 이전 시대 노드를 분야 무관 60% 이상 연구하면 다음 시대가 열린다.
- 던전 유물은 특정 노드의 비용을 50% 줄여준다.
