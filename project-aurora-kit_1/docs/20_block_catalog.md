# 블록 도감

모든 블록의 생김새·움직임·효과를 정리했다. 색은 아트 가이드 탭의 팔레트를 따른다. ‘빛’은 밝기 0\~15(마인크래프트와 같은 단계)다.

## 공통 규칙

- **경도와 도구**: 부수는 시간 = 경도 × 1.5초 ÷ 도구 속도. 맞는 도구가 아니면 ×3.3 느리고, 필요 등급보다 낮은 도구로는 아무것도 나오지 않는다.
- **부수는 연출**: 금이 가는 오버레이 10단계 + 타격마다 블록 색을 따온 작은 파편 파티클. 단단한 금속은 불꽃이 튀고, 나무는 톱밥, 흙은 흙먼지.
- **무너짐**: 모래·자갈·화산재는 아래가 비면 떨어진다.
- **바람**: 잎·풀·꽃·작물·깃발은 쉐이더로 흔들린다(날씨가 나쁘면 더 크게).
- **폭발 저항**: 표의 값이 클수록 폭발에 잘 버틴다. 기준: 흙 2.5, 돌 30, 강철판 150, 흑철판 600.

| 필요 도구 등급 | 채굴 가능한 것 |
| --- | --- |
| 없음 (손) | 흙, 모래, 나무, 잎 |
| 나무 곡괭이 | 돌, 석탄, 구리 |
| 돌 곡괭이 | 철, 초석, 심층암 |
| 철 곡괭이 | 금, 은, 탁한 마석 |
| 강철(6위) 이상 | 다이아몬드, 텅스텐, 맑은 마석 |
| 마강(5위) 이상 | 티타늄, 순수 마석, 흑철 |
| 3위 이상 | 심연 마석 |

## 광석

모든 광석은 돌 버전과 심층암 버전(경도 +1.5)이 있다. 광물 덩어리는 각 재질의 팔레트로 그리고, 알갱이의 모양이 광물마다 다르다.

| 초석 | 2.5 | 회색 돌에 하얀 소금 결정이 꽃처럼 피어남 | 동굴 벽에 집중, 화약 재료 |

## 건축 블록

모든 건축 블록에는 계단·반블록·벽·울타리·다리문·문 변형이 있다(재료에 맞는 것만).

| 블록 | 경도 | 디자인 | 효과 |
| --- | --- | --- | --- |
| 판자 (4수종) | 2.0 | 가로 널빤지 4장, 못 자국 2개 | 마력나무 판자는 나뭇결이 은은히 빛남 |
| 돌벽돌 / 금 간 / 이끼 낀 | 1.5 | 엇갈린 직사각 벽돌 4개, 금·이끼 변형 | 시간이 지나면 물가의 벽돌에 이끼가 낌(끄기 가능) |
| 심층암·현무암·사암 벽돌 | 3.0 / 2.0 / 0.8 | 재질별 색과 크기가 다른 벽돌 무늬 | — |
| 붉은 벽돌 | 2.0 | 산업 시대 공장 벽돌, 회색 줄눈 | 산업 양식 기본 재료 |
| 기와 (점토·청동) | 1.5 / 4.0 | 비늘처럼 겹쳐진 지붕판, 청동은 녹청이 고임 | 비가 오면 빗물 흐르는 입자 |
| 유리 / 색유리(16색) / 강화유리 | 0.3 / 0.3 / 10 | 테두리만 있는 투명, 강화유리는 철사망 | 붙이면 테두리 이어짐, 반사(쉐이더), 강화유리 폭발 저항 100 |
| 장미창 (스테인드글라스) | 0.3 | 3×3 블록이 하나의 원형 무늬를 이루는 색유리 | 빛이 통과하면 바닥에 색 무늬가 비침, 미관 +크게 |
| 콘크리트 (16색) | 2.0 | 이음새 없는 매끄러운 면, 미세한 기포 | 산업 이후 |
| 강철판 | 5.0 | 매끄러운 진회색 판, 모서리 어둡게 | 금속 반사, 연결 텍스처 |
| 리벳 강판 | 5.0 | 판 가장자리에 리벳 점 줄 | 연결하면 리벳 줄이 바깥에만 |
| 격자 강철 | 4.0 | 구멍이 뚫린 격자 발판 | 아래가 비쳐 보임, 액체는 통과 |
| 흑철판 | 8.0 | 거의 검은 판에 청동 테두리 | 폭발 저항 600, 아시리아 양식 |
| 청동 장식판·금박 장식 | 3.0 | 덩굴·톱니바퀴 무늬의 고부조 | 미관 점수 높음 |
| 백석 (매끄러운 흰 돌) | 1.5 | 회색 물결 무늬의 흰 돌 | 성당·왕궁용, 마도 신정 양식 |

**고딕 장식** (모델 블록): 뛰족 아치(2블록 폭 세트), 기둥과 주두, 버팀벽, 가고일 석상(비가 오면 입에서 물이 떨어짐), 첨탑 꼭대기, 원형 창틀, 발코니 난간, 날개 달린 황소 석상(아시리아 양식).

**깃발·현수막**: 왕국 문장이 자동으로 그려지는 깃발(바람에 펄럭임). 건물에 붙이면 미관 +, 영토 밖에 꽂으면 전초기지 자리 표시.

| --- | --- | --- |
| 침대 | 나무 틀에 왕국 색 이불(1×2) | 부활 지점, 주민 1명 거주, 누우면 밤 건너뜀(싱글) |
| 왕좌 | 높은 등받이에 문장, 금·청동 장식 (1×2×1, 높이 3) | 우클릭으로 왕국 관리 창, 선포 시 빛기둥이 하늘로 솟고 영토 경계가 퍼져나감(3초 연출) |
| 문 (나무·철·강철 방폭문) | 재질별, 방폭문은 핸들 휴이 달린 두꺼운 문 | 열고 닫기 0.25초 회전, 철 이상은 신호로만 열림, 방폭문 폭발 저항 300 |
| 사다리·철 사다리 | 벽에 붙는 판 | 오르고 내리기 |
| 책상·의자·탁자·칠판·책장 | 목재 색 따라감, 칠판에는 분필 글씨 | 학교·연구소 필수 가구, 의자는 앉을 수 있음 |
| 창고 상자 / 강철 금고 | 나무 상자, 철 띠 / 다이얼 달린 금고 | 뚜껑이가 열리는 0.3초 애니메이션, 금고는 국고 화폐 저장 |
| 우물 | 돌 테두리와 도르래 지붕 (3×3) | 주민이 물 길을 때 도르래 회전 |
| 제단 | 흰 천을 덮은 돌 탁자와 촛대 | 촛불 살랑임, 신앙 욕구 충족 범위 표시 |
| 종 (경보종) | 청동 종 | 치면 주민이 집으로 대피, 넓은 범위에 울림 |
| 표지판 | 나무 판 | 글자 입력 |

**지휘 탁자**: 영토 지도가 펼쳐진 탁자 위에 작은 부대 말들이 놓여 있고, 부대가 움직이면 말도 따라 움직인다. 요새·전초기지에 둔다. 우클릭하면 전략 지도가 열리고, 멀티에서는 이때 몸이 보호된다.

## 작업·생산 설비

작동 중인 설비는 모두 ‘가동 중’ 모습이 따로 있어 멀리서도 돌아가는지 알 수 있다.

| 설비 | 디자인 | 가동 중 애니메이션·효과 |
| --- | --- | --- |
| 작업대 | 두꺼운 나무 상판에 공구가 걸려 있음 | 제작 시 뚝딱거리는 소리 |
| 화로 | 돌 상자, 정면에 아치형 아궁이 | 아궁이에 불이 일렁임(빛 13), 굴뚝 연기 |
| 대장간 모루 | 검은 철 모루 (모델) | 망치질마다 불꽃이 튀고 카랑 소리 |
| 용광로 | 내화 벽돌 노, 철제 투입구 (2×2×3) | 위로 불꽃·검은 연기, 출구에 쇳물이 빛나며 흐름(빛 15) |
| 분쇄기 | 맷돌 → 산업형은 롤러 2개 | 맷돌이 돌고 청록 가루가 뿌연게 날림 |
| 각인 전용 작업대 I·II·III | I: 흑단 상판에 청동 테두리 → II: 공중에 링 1개 → III: 링 3개와 결정 기둥 | 작업 중 장비 위로 문양이 떠올라 회전하고 분말이 빛의 선으로 빨려 들어감. 성공 시 섬광, 실패 시 보라 연기 |
| 회로 작업대 | 확대경이 달린 정밀 작업대 | 기판 위로 빛나는 선이 그려짐 |
| 연구대 | 책·지도·플라스크가 어질러진 책상 | 연구 중 페이지가 넘어가고 가끔 작은 빛 방울 |
| 마력로 | 강철 원통 안에 떠 있는 마석 코어, 유리창 4면 (2×2×2) | 코어가 회전하며 맥동(출력이 클수록 빠름, 빛 12), 과부하면 빨간 빛 + 경고음 |
| 마력선 (구리·은·금) | 바닥·벽에 깔리는 얇은 선, 재질 색 | 마력이 흐르면 빛나는 점이 방향대로 흘러감 |
| 충전기 | 배터리 거치대 4칸 | 충전 중 배터리 눈금이 차오름, 완료 시 초록 불 |
| 마력 전기로 / 고온 마력로 | 청록 전극이 꽂힌 도가니 / 두꺼운 항아리형 노 | 전극 사이에 번개가 튀고(전기로), 노 안이 하얇게 달아오름(고온) |
| 정련로 I·II·III | 표시등 1·2·3개가 달린 금속 탱크 | 단계마다 표시등이 켜짐, III는 내부 금속이 공중에 떠서 정제됨 |
| 공명 제련로 | 공중에 떠 있는 지름 3블록 링 세 개가 감싼 구체 (3×3×3) | 링이 서로 다른 축으로 회전, 오로라빛(청·금·보라)이 번갈아 빛남, 완성 순간 충격파 |
| 시추기 | 바닥에 박힌 철제 펌프잭 | 말 머리처럼 위아래로 끄덕임, 검은 원유 튀김 |
| 정유기 | 세로 탱크와 배관 (2×2×4) | 파이프에서 증기, 꼭대기에 작은 불꽃 |
| 조립 설계대 | 청사진이 펼쳐진 큰 책상 | 사용 시 탈것의 홀로그램식(청록 반투명) 미리보기 |
| 의식진 | 바닥에 새겨진 원형 마법진 (5×5) | 준비 중 바깥 원부터 안쪽으로 빛이 차오름, 완료 시 하늘로 빛기둥 |

## 마력 회로 블록 (레드스톤 같은 장치)

| 블록 | 디자인 | 동작 |
| --- | --- | --- |
| 마법진 선 | 바닥에 그리는 가는 문양 선 | 신호가 흐르면 청록으로 밝아짐, 15칸까지 전달 |
| 마력 스위치 / 버튼 / 압력판 | 황동 손잡이 / 동그란 단추 / 밟는 판 | 켜면 문양이 빛남, 버튼은 1초 |
| AND / OR / NOT 게이트 | 문양이 다른 판 (∧ ∨ ¬) | 입력·출력 방향 화살표 표시 |
| 타이머 | 모래시계 문양 | 1\~60초 간격 신호, 문양이 돌아감 |
| 중계기 | 화살표 문양 | 신호 세기 회복, 지연 0.1\~0.4초 |
| 감지기 | 눈 모양 결정 | 주민·적·플레이어 중 고른 대상이 들어오면 신호 |
| 마력 피스톤 | 청동 판이 달린 블록 | 블록을 밀고 당김, 0.15초 |
| 마력 램프 | 유리 안 결정 | 신호가 오면 밝아짐(빛 15) |

예시: 성문 앞에 감지기(적)를 두고 마력 피스톤에 연결하면, 적이 다가오는 순간 피스톤이 흑철판을 밀어 내 성문을 막는다. 여기에 타이머를 더하면 적이 사라진 뒤 10초 뒤에 다시 열린다.
