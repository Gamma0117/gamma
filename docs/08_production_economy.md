# 생산 체인·경제 수치

직업 탭의 생산량으로 계산한 예시다. 주민 100명이면 농부 10\~15명, 제빵사 3명 정도가 식량을 맡는다.

## 식량 균형

밭 1칸은 3일마다 밀 1.5개(평균), 빵 1개 = 밀 3개 = 배고픔 5, 주민 1명은 하루 10을 먹는다.

| 농업 수준 | 농부 1명(밭 81칸) 밀/일 | 부양 인원 |
| --- | --- | --- |
| 초반, 무학 | 40 | 약 7명 |
| + 윤작 (LIF-1) | 49 | 약 8명 |
| + 비료 (LIF-5) | 63 | 약 10명 |
| + 농업학 학사 | 79 | 약 13명 |
| + 농업학 박사 | 107 | 약 18명 |

제빵사 1명(빵 60)은 30명을 먹인다. 어부·목동의 생선·고기는 음식 다양성(미식가 성향, 욕구 3단계)을 채운다.

## 체인 예시

**강철 검 하루 8자루**

1. 검 8 = 강철 주괴 16 → 대장장이 2명
2. 강철 16 = 철 16 + 석탄 32 → 제련공 1명 (용광로 1기)
3. 철 16 → 광부 1.3명, 석탄 32 → 광부 1.6명
4. 합계: 광부 3, 제련공 1, 대장장이 2 = 6명이 병사 8명을 하루에 무장시킨다.

**빵 체인 (주민 30명)**: 농부 5명(밀 200) → 제분소 → 제빵사 1명(빵 60)

**의복 체인 (주민 50명)**: 의복 하루 5벌 필요 → 재단사 1명 + 목동 1명(양털) 또는 목화밭 농부 1명

**마력 배터리 하루 3개**: 기계공 1명 + 맑은 마석 3(광부) + 구리 6 + 은 3 + 1세대 마법진 3(기계공 0.4명분)

## 연구 속도 예시

연구원 1명 = 20 RP/일 × 교육·학위 보너스. 플레이어의 분야 포인트를 더하면 더 빨라진다.

| 규모 | 연구원 | 평균 보너스 | RP/일 | 대표 노드 | 걸리는 시간 |
| --- | --- | --- | --- | --- | --- |
| 작은마을 | 5 | ×1.10 | 110 | 300 RP (중세 끝) | 약 1시간 20분 |
| 중간마을 | 12 | ×1.15 | 276 | 1,500 (증기) | 약 2시간 40분 |
| 큰마을·소국 | 30 | ×1.40 | 840 | 5,000 (산업) | 약 3시간 |
| 왕국 | 60 | ×1.60 | 1,920 | 20,000 (근대) | 약 5시간 |
| 제국 | 200 | ×1.90 | 7,600 | 80,000 (제트기) | 약 5시간 |

여러 노드를 동시에 연구할 수 있다(연구소별로 노드 하나씩).

## 화폐와 기준 가격

1 금화 = 10 은화 = 100 동화. 실제 가격은 AI 시장의 수요·공급에 따라 ±50% 안에서 움직인다.

| 품목 | 기준가 (동화) |
| --- | --- |
| 원목 / 돌 | 1 / 1 |
| 빵 / 구운 고기 | 2 / 4 |
| 석탄 / 원유 / 연료 | 3 / 5 / 15 |
| 구리 주괴 / 철 주괴 / 강철 주괴 | 6 / 8 / 20 |
| 은 주괴 / 금 주괴 | 40 / 100 |
| 다이아몬드 / 텅스텐 / 티타늄 | 300 / 250 / 600 |
| 마석: 탁한 / 맑은 / 순수 / 심연 | 30 / 150 / 800 / 5,000 |
| 의복 / 생필품 / 사치품 | 15 / 25 / 80 |
| 강철 검 / 소총 / 소총탄 16발 | 60 / 200 / 20 |
| 마력 배터리 | 300 |

## 세금·유지비

- **세금**: 주민 1명당 하루 5동화 × 세율(낮음 0.6 / 보통 1.0 / 높음 1.5 / 수탈 2.2) × 행복도 생산 계수. 예: 주민 1,000명, 보통 세율, 행복도 70 → 하루 5,000동화 = 50금화.
- **유지비**: 군사 시설과 모병제 병사만 화폐 유지비가 든다 (병영 5동화/일, 요새 50동화/일, 모병 병사 3동화/일). 나머지는 물자 유지(연료·배터리)만.

## 영토 확장 비용

```latex
\text{청크 1개 비용} = (\text{동화 } 20 + \text{원목 } 16 + \text{돌 } 16) \times \left(1 + \frac{\text{보유 청크 수}}{200}\right)
```

보유 청크가 1,000개를 넘으면 청크마다 탁한 마석 1개가 추가로 든다.

| 영토 크기 | 보유 청크 | 청크당 화폐 | 여기까지 누적 화폐 | 비교: 그 규모의 하루 세수 |
| --- | --- | --- | --- | --- |
| 100×100 (시작) | 39 | 24동화 | 0 | — |
| 약 200×200 | 160 | 36동화 | 약 36금화 | 중간마을 약 8금화 |
| 약 390×390 | 600 | 80동화 | 약 291금화 | 소국 약 30금화 |
| 약 500×500 | 1,000 | 120동화 | 약 691금화 | 왕국 약 50금화 |
| 약 1,000×1,000 | 4,000 | 420동화 | 약 8,790금화 | 대제국 약 500금화 |

주민 1명에 필요한 땅은 집·밭·일터를 합쳐 약 100블록²로 잡았다. 그래서 주민 1만 명 제국은 약 1,000×1,000 영토가 필요하다.
