# 주민·직업·성향·행복도

주민 한 명의 하루 생산량은 아래 공식으로 정해진다. 주민은 낮 20분 동안 일하고 밤 10분은 잔다.

```latex
\text{생산량} = \text{기본 생산} \times \text{교육·학위} \times \text{도구 계수} \times \text{각인} \times \text{행복도 계수} \times \text{성향}
```

도구 계수 = 도구 재료 공격 배율의 제곱근 (철 0.87, 강철 1.0, 마강 1.3, 오로라 합금 3.8). 무기보다 완만하게 오르게 해서 경제가 폭주하지 않게 한다.

## 직업

기본 생산은 무학·강철 도구·행복도 60 기준.

- **숙련도**: 직업별 1\~10. 하루 일할 때마다 오르고, 레벨당 생산 +4% (최대 +40%). 다른 직업으로 바꿔도 원래 숙련도는 남는다.

## 성향

주민은 태어나거나 이주할 때 성향 1\~2개를 받는다.

| 성향 | 효과 |
| --- | --- |
| 부지런함 | 생산 +15% |
| 게으름 | 생산 −15%, 여가 효과 +50% |
| 학구적 | 교육 기간 −25%, 연구 +10% |
| 손재주 | 제작·대장·각인 +20% |
| 튼튼함 | 체력 +4, 광부·채석 생산 +10% |
| 호전적 | 병사 공격 +10%, 징집돼도 행복도 하락 없음 |
| 겁쟁이 | 병사 사기 −15, 민간 직업에서 행복도 +5 |
| 마력 친화 | 마도사·조각사 +20% |
| 신실함 | 신앙 욕구 가중치 2배, 충족 시 행복도 +10 |
| 미식가 | 음식 종류 3가지 이상이어야 만족, 충족 시 +8 |
| 사교적 | 여가·선술집 효과 +50% |
| 은둔형 | 공동 주택에 살면 행복도 −10 |
| 야행성 | 야간 교대 불이익 없음 |
| 검소함 | 생필품·사치품 소비 −30% |
| 사치 선호 | 사치품 욕구가 등급보다 일찍 생김 |
| 향수병 | 이주 후 5일간 행복도 −10 |

## 소비량 (주민 1명, 하루)

| 항목 | 양 | 욕구 단계 |
| --- | --- | --- |
| 음식 | 배고픔 10 (빵 2개 분량) | 1 |
| 물 | 우물·급수탑 반경 32블록 안에 살면 충족 | 2 |
| 의복 | 0.1벌 (10일에 한 벌) | 2 |
| 생필품 | 0.2개 | 4 |
| 사치품 | 0.1개 | 5 |

병사는 음식 12를 먹는다.

## 행복도

기본 50에서 시작해 욕구 충족·미관·법령·사건이 더해진다. 범위는 0\~100.

| 요인 | 값 |
| --- | --- |
| 욕구 1단계 (각 욕구) | 충족 +5 / 미충족 −15 |
| 욕구 2단계 | +4 / −8 |
| 욕구 3·4단계 | +3 / −5 |
| 욕구 5단계 | +2 / −3 |
| 미관 점수 | +1 \~ +10 |
| 세율 낮음 / 보통 / 높음 / 수탈 | +5 / 0 / −10 / −25 |
| 전쟁 피로 | 전쟁 10일째부터 하루 −1 (최대 −20) |
| 가족 사망 | −20 (5일간) |
| 승전 | +5 (3일간) |

| 행복도 | 상태 | 생산 계수 |
| --- | --- | --- |
| 80\~100 | 만족 | ×1.2 |
| 60\~79 | 보통 | ×1.0 |
| 40\~59 | 불만 | ×0.85 |
| 20\~39 | 태만 (자주 쉼) | ×0.65 |
| 0\~19 | 절망 (일을 거의 안 함, 반란·이탈은 없음) | ×0.4 |

**예시 (촌락의 농부)**: 음식·집·잠 충족 +15, 물 충족 +4, 의복 부족 −8, 치안 충족 +4, 미관 +3 → 50 + 18 = 68 (보통, ×1.0). 재단소를 지어 의복을 채우면 80(만족, ×1.2)이 되어 밀 생산이 20% 늘어난다.
