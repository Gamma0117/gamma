## P0 엔진 기반 (상세: `22_p0_tech.md`)

목표: 렌더거리 16청크에서 60fps로 걷고, 블록을 부수고 놓고, 저장·불러오기가 되며, 싱글도 내장 서버로 도는 엔진.

- [x] **P0-1 빌드 환경, 창 띄우기** — 완료 기준: 빈 창이 60fps로 뜨고 닫힘 (2026-09-30 완료. Linux: GCC·Clang 빌드, Xvfb 스모크. Windows: VS 2022 폴더 열기·F5·테스트 탐색기, 120Hz에서 VSync 약 119fps, 창 크기 변경·Esc·X 종료)
  - `vcpkg.json`, `CMakeLists.txt`, `CMakePresets.json`(debug / release), 폴더 뼈대, `app/main.cpp`
  - GLFW 창 + OpenGL 4.5 core 컨텍스트 + glad, VSync, 창 크기 변경 처리
  - Dear ImGui 초기화(빈 디버그 창), Catch2 테스트 하나(`1 + 1 == 2` 수준)로 ctest 연결 확인
- [x] **P0-2 코어: 로그·잡 시스템·프로파일러** — 완료 기준: F3 디버그 화면에 프레임 시간 표시 (2026-09-30 완료. Linux: GCC·Clang 빌드, 단위 테스트 28개(워커 시작 실패 주입 포함) + Xvfb 스모크(F3 화면 그림), TSan·ASan/UBSan 통과, xdotool로 F3 켜기·끄기와 키 반복 무시 확인, tracy-capture 0.14.1로 존·프레임·로그 수신 확인. Windows 확인 전)
  - 로그(레벨·파일 출력), 고정 20tps 서버 루프와 가변 프레임 렌더 루프 분리, 워커 스레드 풀(코어 수 − 2), Tracy 연결
- [x] **P0-3 데이터 로더: 블록 JSON → 레지스트리** — 완료 기준: 틀린 JSON을 로그로 알려줌 (2026-09-30 완료. 블록 6개 + 내장 2개 = 8개·상태 10개, 틀린 파일마다 파일·필드·이유를 로그로 알리고 창 전에 종료 코드 1. Linux: GCC·Clang, TSan·ASan/UBSan, 앱 수준 ctest(잘못된 --game-dir, DISPLAY 없이 틀린 데이터). 검토 반영: 읽을 수 없는 폴더·항목과 깨진 링크를 오류로, 속성 값 중복 검사를 선형으로. Windows 확인 전)
  - `game/data/aurora/blocks/*.json` 몇 개(돌·흙·풀·조약돌·원목·판자)로 시작, `aurora:` ID 레지스트리, 16비트 블록 상태 ID
- [x] **P0-4 청크 구조 + 평지 월드** — 완료 기준: 평지 데이터 생성 (2026-09-30 완료. 서버 스레드가 만든 월드가 워커로 원점 둘레 289청크를 생성하고 F3에 loaded / pending / failed 수를 보여줌. 평지 층은 `worldgen/flat.json`. Linux: GCC·Clang, TSan·ASan/UBSan, 핵심 규칙마다 일부러 망가뜨린 코드로 테스트가 실패하는지 확인. Windows 확인 전)
  - 16³ 섹션(팔레트 0/1/2/4/8비트 + 257종부터 16비트 직접 저장), 섹션 24개짜리 청크와 높이맵, 청크 관리자(`World`), 평지 생성기, 단위 테스트
  - 서버 루프가 밀린 틱을 몰아 돌 때도 틱 사이마다 stop 요청을 확인한다(`requestStop()`, P0-2 검토 항목). `run()` 전체에 예외 경계
  - 섹션·좌표 테스트(P0-3 검토 메모), 월드 작업 수명 테스트(중복 요청, 늦은 결과, 월드를 먼저 파괴, 제출 거부·생성 실패, 재시도)
  - 월드는 만들 때의 블록 레지스트리(`shared_ptr<const BlockRegistry>`)를 붙잡고 쓴다. `/reload`로 번호가 바뀔 때 섹션의 숫자 ID를 어떻게 다시 매길지는 reload를 만들 때 정한다
- [ ] **P0-5 메싱·렌더링·카메라** — 완료 기준: 평지를 날아다니며 볼 수 있음
  - 그리디 메싱 + 꼭짓점 AO, 32px 텍스처 배열, 자유 비행 카메라, 워커에서 메싱
  - 청크를 불러오는 중심(지금은 원점 고정, 반경 8)을 카메라·플레이어 위치로 옮긴다. 중심이 움직이면 `Spawn area ready` 로그는 처음 한 번만 찍힌다
  - (P0-4 검토 메모) 서버가 가진 청크·섹션의 불변 복사본을 클라이언트와 메싱 워커에 넘기는 경로를 먼저 정한다. `World::chunk()` 포인터를 다른 스레드로 넘기면 소유권 규칙을 깨고, 청크를 내리면 수명도 끝난다
  - (P0-4 검토 메모) 메싱 요청·결과에 청크 로드 세대와 섹션 수정 번호를 붙여, 내렸다 다시 불러온 좌표나 블록이 바뀐 섹션의 옛 결과를 버린다. GPU 업로드는 GL 컨텍스트가 있는 메인 스레드에서 한다
  - (P0-4 검토 메모) 면 제거·꼭짓점 AO에 쓰는 이웃 데이터도 복사본에 넣고, 이웃 청크가 도착하거나 내려가면 경계 섹션을 다시 메싱한다. 이웃이 아직 없을 때의 임시 표시 규칙도 정한다
- [ ] **P0-6 플레이어 이동·충돌** — 완료 기준: 걷고 뛰고 계단 오르기
  - AABB vs 블록 격자, 0.6블록 자동 오르기, 중력 32블록/초², 최대 낙하 78블록/초
- [ ] **P0-7 블록 부수기·놓기** — 완료 기준: 금 가는 연출·파편까지
  - 레이캐스트 선택, 선택 윤곽선, `destroy_stage_0~9` 금 텍스처, 파편 입자, 섹션 재메싱
- [ ] **P0-8 지형 생성** — 완료 기준: 바이옴 11종·동굴·광맥이 보이는 월드
  - 결정성 테스트(같은 시드·좌표 → 같은 청크 해시)
  - 청크에 바이옴을 추가한다(P0-4에서 미룸)
- [ ] **P0-9 조명·AO** — 완료 기준: 동굴이 어둡고 횃불이 밝힘
  - 섹션에 하늘빛·블록빛(각 4비트)을, 청크 상태에 "조명 완료"를 추가한다(P0-4에서 미룸)
- [ ] **P0-10 기본 쉐이더** — 완료 기준: 그림자·안개·물·블룸·낮밤
- [ ] **P0-11 내장 서버 분리** — 완료 기준: 클라이언트가 패킷으로만 월드를 받음
  - 접속 때 서버의 블록 상태 번호표(상태 문자열 목록)를 먼저 보낸다
  - 서버 스레드 시작 실패 회귀 테스트(스레드 생성 실패 주입을 공통으로 만들 때. P0-2 검토에서 넘어온 항목)
  - 패킷 직렬화 왕복 테스트
- [ ] **P0-12 저장·불러오기, 성능 점검** — 완료 기준: 16청크 60fps, 저장 후 그대로 복원
  - 저장 전에 섹션 `compact()`로 쓰지 않는 팔레트 항목을 정리한다
  - 섹션 팔레트는 숫자 ID가 아니라 상태 문자열로 저장. 없는 블록은 `aurora:unknown`으로 읽되 원래 문자열을 다시 저장할 때 잃지 않는 방법을 정한다(P0-3 결정)
  - 영역 파일 + LZ4, 저장 왕복 테스트, 청크 1,000개 생성·메싱 벤치마크
