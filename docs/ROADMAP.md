## P0 엔진 기반 (상세: `22_p0_tech.md`)

목표: 렌더거리 16청크에서 60fps로 걷고, 블록을 부수고 놓고, 저장·불러오기가 되며, 싱글도 내장 서버로 도는 엔진.

  - 섹션·좌표 테스트(P0-3 검토 메모), 월드 작업 수명 테스트(중복 요청, 늦은 결과, 월드를 먼저 파괴, 제출 거부·생성 실패, 재시도)
  - 월드는 만들 때의 블록 레지스트리(`shared_ptr<const BlockRegistry>`)를 붙잡고 쓴다. `/reload`로 번호가 바뀔 때 섹션의 숫자 ID를 어떻게 다시 매길지는 reload를 만들 때 정한다
- [x] **P0-5 메싱·렌더링·카메라** — 완료 기준: 평지를 날아다니며 볼 수 있음 (2026-10-01 완료. Xvfb·Mesa에서 풀 평지가 그려진 시작 화면을 스크린샷으로 검사하고, xdotool로 마우스 잡기·Ctrl+W 비행·시선 회전·Esc 놓기·F3 패널 클릭을 확인. Linux: GCC·Clang, ASan/UBSan, TSan(단위 테스트는 억제 없이, 창 테스트는 Mesa 억제 파일로), 메셔 규칙마다 일부러 망가뜨린 코드로 테스트 실패 확인. Windows 확인 전)
  - 그리디 메싱 + 꼭짓점 AO, 32px 텍스처 배열, 자유 비행 카메라, 워커에서 메싱
  - 청크를 불러오는 중심을 카메라 위치로 옮겼다(렌더 거리 8, 서버는 9를 불러옴). `Spawn area ready` 로그는 처음 한 번만
  - 검토 메모 반영: 서버는 불변 스냅샷만 넘기고, 메싱 키는 로드 세대와 스탬프로 옛 결과를 버리고, 이웃이 모두 오기 전에는 그리지 않는다(임시 메시 없음). 업로드는 메인 스레드
  - 구현 검토 반영: 면이 없어진 섹션(Empty)도 렌더러에 넘겨 옛 GPU 메시를 지운다. 최소화 중 포커스 상실을 잃지 않고 마우스를 놓는다
- [x] **P0-6 플레이어 이동·충돌** — 완료 기준: 걷고 뛰고 계단 오르기 (2026-10-02 완료. 서버가 20tps 틱마다 한 걸음씩 플레이어를 움직이고, 클라이언트는 같은 물리로 미리 계산해 서버 결과로 맞춘다. 화면 확인 범위: 걷기·달리기·점프, 한 칸 계단을 점프로 오르기, 벽·통로·구덩이(시험 코스), 포커스를 잃거나 Esc로 놓으면 멈춤, F3 자유 비행 전환. 0.6블록 자동 오르기와 계단 모양은 부분 블록이 없어 화면에서는 아직 볼 수 없고, 실제 World·ClientWorld 블록 조회를 거치는 CPU 통합 테스트로 확인. Linux: GCC·Clang, ASan/UBSan(halt_on_error), TSan(단위 테스트는 억제 없이, 창 테스트는 Mesa 억제 파일로), `nobody` 권한 실행, 규칙마다 일부러 망가뜨린 코드 31가지가 모두 테스트에 걸림, Xvfb·xdotool로 걷기·달리기·점프·계단·포커스 상실·자유 비행 확인. Windows 확인 전)
  - AABB vs 블록 격자(이동 구간 전체를 쓸어 얇은 벽도 통과하지 않음), 0.6블록 자동 오르기(점프로 올라가는 중에는 하지 않음), 중력 32블록/초², 최대 낙하 78블록/초. 수치는 `player/movement.json`
  - 미로드 청크: 불러오지 않은 청크 기둥은 높이와 상관없이 벽(규칙 A), 몸이 걸친 기둥이 미로드면 그 틱은 정지(규칙 B). 월드 아래는 막힘, 위는 빈칸
  - 서버 권한: 입력 하나가 아니라 서버 틱 하나가 한 걸음. 입력이 없으면 중립으로 진행(중력 계속, 되풀이 없음). 입력 대기열 4개, 채우기 대기 최대 2틱, 확인 번호는 정리가 끝난 연속 구간의 끝. 포커스 상실·Esc·최소화·자유 비행 전환은 그 자리에서 Neutralize로 대기 입력을 중립화
  - 클라이언트 예측: 기록 40개(가득 차면 멈춤), 공백이 생기면(계약상 없음) 경계까지 기다리는 방어 재동기화, 보간은 다시 계산한 결과로만. 플레이어 위치는 서버가 정하므로 `setViewCenter`를 없애고 자유 비행 중에만 쓰는 `setViewCenterOverride`로 바꿨다
  - 자유 비행 카메라(P0-5)는 F3 체크박스로 남겼다(디버그). 평지 프리셋에 `boxes`를 더해 스폰 남쪽에 시험 코스를 놓았다. 시작 pitch는 −25(눈 높이 장면에서 스크린샷 검사의 하늘 영역을 지키려고)
  - 입력의 포커스 규칙(P0-5)을 키에도 적용: 포커스를 잃으면 그 전의 키 눌림도 버리고, 포커스 없는 동안의 키 눌림은 기록하지 않는다
  - 검증 중 찾은 P0-5 버그: 빈 텍스처 파일을 읽을 때 `memcpy(nullptr, nullptr, 0)`(정의되지 않은 동작, UBSan halt_on_error로 발견)을 고침
