# 조작·UI

마인크래프트 조작을 기본으로 두고, 왕국·전략 기능을 단축키로 더했다. 모든 키는 바꿀 수 있다.

## 영웅 모드 키

| 키 | 동작 |
| --- | --- |
| W A S D / Space / Shift / Ctrl | 이동 / 점프 / 웅크리기 / 달리기 |
| 좌클릭 / 우클릭 | 공격·채굴 / 사용·막기·조준 |
| 좌클릭 길게 | 차지 강공격 |
| Alt + 방향 | 회피 구르기 |
| 1\~9 / 휠 | 핫바 |
| E / Q | 인벤토리 / 버리기 |
| R | 재장전 |
| F | 보조 손 사용 (건틀릿 주문 등) |
| Z / X / C | 주문 슬롯 1·2·3 |
| G (누르고 있기) | 지휘 휠 |
| M | 전략 지도 모드 |
| K | 왕국 관리 창 |
| J | 연구 트리 |
| B | 건축·청사진 모드 |
| H | 영웅 능력(스탯·특성) |
| V / F5 | 1인칭·3인칭 전환 |
| T / / | 채팅 / 명령어 |
| F3 | 디버그 정보 |
| Esc | 메뉴·일시정지(싱글) |

- **P0 단계(인벤토리 전)**: 좌클릭을 누르고 있으면 채굴, 우클릭은 놓기 한 번, 1\~9는 핫바 대신 `player/interaction.json`의 블록 팔레트 칸을 고른다(팔레트 길이 밖의 키는 무시). 마우스를 잡는 클릭은 공격으로 세지 않아 잡은 뒤 다시 눌러야 한다. Esc는 아직 메뉴가 아니라 마우스를 놓기만 한다.

## 탈것 키

| 키 | 동작 |
| --- | --- |
| F | 탑승·하차 |
| W S / A D | 전진·후진 / 회전 |
| Space / Shift | 상승 / 하강 (항공·비행함·잠항) |
| 좌클릭 / 우클릭 | 주무장 / 부무장 |
| 1\~4 | 승무원 자리 이동 (운전석·포수석 등) |
| R | 반중력·보호막 마법진 켜기·끄기 |

## 전략 지도 모드

| 조작 | 동작 |
| --- | --- |
| 좌클릭 / 드래그 | 부대 선택 / 영역 선택 |
| 우클릭 | 이동·공격 (대상에 따라 자동) |
| Shift + 우클릭 | 명령 대기열 추가 |
| Ctrl + 1\~9 / 1\~9 | 부대 그룹 지정 / 선택 |
| F1\~F6 | 진형 변경 |
| 휠 / 가운데 드래그 | 확대·축소 / 카메라 회전 |
| Space | 일시정지 (일반 난이도 싱글만) |

## 화면 구성

- **HUD**: 왼쪽 위 왕국 요약(주민·식량 여유 일수·행복도·국고), 오른쪽 위 미니맵·시간·날씨, 아래 체력·배고픔·마력·핫바·주문 슬롯, 오른쪽 아래 알림 로그.
- **알림 등급**: 회색(정보: 완공·연구 완료) · 노랑(주의: 식량 3일분 미만, 건물 비활성) · 빨강(위협: 습격 경보, 선전포고). 빨강 알림은 클릭하면 지도에서 위치를 보여준다.
- **왕국 관리 창 (K)**

| 탭 | 내용 |
| --- | --- |
| 개요 | 등급·다음 등급 조건, 자원 수지 그래프, 경고 |
| 주민 | 주민 목록(직업·교육·학위·성향·행복도 정렬), 직업 인원 상한 |
| 생산 | 생산 체인 흐름도, 병목 표시 |
| 교육 | 학교 정원, 전공별 학위 보유자 수, 의무교육 |
| 군사 | 부대 편성, 장군, 보급 상태 |
| 외교 | 세력별 관계도·협정·제안 |
| 정부 | 부·청·장관, 법령 슬롯, 기본 정책 |

한글 UI를 기본으로 하고, 모든 문자열은 번역 파일로 분리해 영어 등 다른 언어를 붙일 수 있게 한다.
