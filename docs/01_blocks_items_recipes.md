# 블록·아이템·제작법

P1에서 구현할 목록 초안이다. 제작은 마인크래프트식 3×3 격자 대신, 설비별 레시피 목록에서 재료가 있으면 골라 만드는 방식을 제안한다(합금·부품 종류가 많아 격자 배치가 번거롭고, 주민에게 제작을 맡기기도 쉽다).

## 자연 블록

| 분류 | 블록 |
| --- | --- |
| 흙·모래 | 흙, 풀 블록, 모래, 자갈, 점토, 눈, 얼음 |
| 암석 | 돌, 심층암(y 0 아래), 현무암(화산), 사암, 파괴 불가 기반암(y −50) |
| 나무 | 원목·잎: 참나무, 자작나무, 침엽수, 마력나무(발광) |
| 액체 | 물, 용암, 원유(유정) |
| 마력 | 마석 결정(지표), 오염된 흙(마력 오염 지역) |

## 광석

석탄, 구리, 철, 금, 은, 다이아몬드, 텅스텐, 티타늄, 마석(탁한·맑은·순수·심연), 초석(화약 재료, 동굴 벽 부산물)

## 건축 블록

- 판자(수종별), 돌벽돌, 심층암 벽돌, 현무암 벽돌, 기와, 유리, 콘크리트(산업)
- 금속: 강철판, 리벳 강판, 청동 장식판, 금박 장식
- 고딕 장식: 아치, 기둥, 버팀벽, 장미창 유리, 석상 받침
- 형태 변형: 모든 재료에 계단·반블록·벽·울타리·문·다리문
- 조명: 횃불 → 기름 등불 → 마력등(마력망 필요)

## 재료·가공품

막대, 판자, 각 금속 주괴(순도 표시), 합금 주괴, 마석 분말(4등급), 기판(구리·은·금판, 티타늄 틀), 마법진(1\~4세대), 주문 회로판, 마력 배터리, 고밀도 마력 셀, 화약, TNT, 마력 폭약, 고무, 수지, 디젤·가솔린, 천, 가죽, 콘크리트 가루

## 도구

곡괭이, 도끼, 삽, 괭이, 건축 망치(블록 회수), 렌치(기계 조작·수리) — 모두 재료별. 채굴 속도는 재료 공격 배율의 제곱근에 비례(초안: 너무 빨라지지 않게).
