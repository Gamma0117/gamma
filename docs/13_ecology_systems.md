## 저장

- 자동 저장 5분마다(1\~15분 설정), 월드를 나갈 때 저장.
- 일반: 수동 저장 가능, 월드 종료 시 백업 3개 유지.
- 하드코어: 자동 저장만, 백업 없음. 사망하면 월드 폴더를 삭제하고 통계 화면만 남긴다.
