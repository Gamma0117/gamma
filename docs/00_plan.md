## 1. 개요

마력과 1950년대 수준 기술이 결합한 세계에서, 플레이어가 직접 싸우고 짓는 왕이 되어 왕국을 키우는 복셀 샌드박스 + 왕국 경영 + 실시간 전략 게임이다. 엔진부터 C++20으로 직접 만든다.

- **장르**: 복셀 샌드박스(채집·제작·건축) + 콜로니 경영(주민 욕구·생산) + 실시간 전략(군대·외교·전쟁)
- **플레이어 역할**: 직접 싸우고 캐고 짓는 영웅이자, 주민에게 명령하는 통치자
- **재미의 세 축**: ① 무게감 있는 근접·사격 액션 ② 마을이 제국이 되는 경영 ③ 마석 기술로 전함을 하늘에 띄우는 기술 성장
- **플랫폼**: PC(Windows 우선, Linux 지원), 싱글플레이 먼저, 멀티플레이는 이후 추가(구조는 처음부터 대응)
- **톤**: 어둡고 장엄한 고딕 산업 판타지. 두꺼운 중장갑, 굉음 내는 기계, 룬 회로가 청록빛으로 빛나는 금속
- **가제**: 프로젝트 오로라(Project Aurora)

블록·건물·기술 트리·무기·몬스터·AI 세력·주민·경제·법령·군사·각인·조작·시스템 수치·아트 가이드·데이터 구조·보스·전차·사운드·설정 등 19개 상세 목록은 상세 목록 탭에 있다.

## 2. 세계관·아트 방향

마력은 에너지원이고, 마석 분말로 새긴 마법진은 반도체다. 그래서 기술 상한은 현실의 1950년 무렵이지만, 진공관·트랜지스터 자리를 마법진이 대신하면서 현실보다 뛰어난 장치(반중력, 마력 장갑, 탑승형 로봇)가 가능하다.

- **세계 설정**: 마석 광맥이 지하와 마력 지대에 흩어져 있고, 마력이 짙은 숲·능선에서 몬스터가 번식한다. 여러 왕국이 마석을 둔러싸고 경쟁한다.
- **비주얼 키워드**: 고딕 성당식 요새, 두꺼운 판금 파워아머, 리벳·파이프·배기구, 해골·인장 장식, 연기와 불꽃, 청록·호박색 마력 발광
- **팔레트**: 강철 회색, 흑철, 녹슨 구리, 금 장식, 마력 청록(발광), 경고 적색
- **해상도**: 1블록 = 32픽셀(블록·아이템 32×32, 사람 스킨 128×128). 높이맵에서 뽑은 명암·하이라이트와 노멀·발광·재질 맵을 써서 평평한 옛날 도트가 아닌 질감 있는 3D 화면을 만든다
- **워해머 40k는 분위기 참고만**: 이름·문장·실루엣은 모두 자체 디자인으로 만든다 (예: 탑승형 로봇 = ‘철관 보행기’).

| 세력 | 성향 | 시각 구분 |
| --- | --- | --- |
| 플레이어 왕국 | 자유 | 문장·깃발·색을 플레이어가 디자인 |
| 아시리아 제국 | 최강 AI 제국, 군사·마력 강국, 최종 목표(18장) | 흑철 + 청동, 계단식 성채와 날개 달린 황소 석상 |
| 아틀란 왕국 | 조금 강함, 해양·마력 기술 | 백은 + 짙은 청색, 해안 절벽의 수정 첨탑 도시 |
| 상업 연합 | 교역·해양 | 구리 + 청록, 항구·비행선 |
| 마도 신정 | 마법·연구 | 백석 + 금, 첨탑과 마법진 |
| 타지리 왕국 | 조금 약함, 사막 석유 무역·기병 | 모래색 사암 + 주홍, 돔 지붕과 유정 탑 |
| 변경 부족 | 약탈·기동 | 가죽 + 나무, 목책 요새 |
| 몬스터 | 적대 | 마력 오염의 보라·녹색 발광 |

## 3. 핵심 게임 루프

**자원이 군대가 되고, 전쟁이 다시 영토와 자원이 된다** (한 바퀴를 돌 때마다 왕국 등급과 시대가 올라간다)

| 순서 | 단계 | 설명 |
| --- | --- | --- |
| 1 | 채집·채굴 | 나무·돌·광석·마석 |
| 2 | 제련·생산 | 합금·순도 정련·생필품 |
| 3 | 주민·건축 | 욕구 충족 → 인구 증가 (→ 연구원·세금) |
| 4 | 연구·교육 | RP·XP로 기술 해금 |
| 5 | 장비·각인·군대 | 징집·장군·전쟁기계 |
| 6 | 토벌·전쟁·외교 | 둥지·던전·AI 왕국 (→ 영토 확장·희귀 자원 → 1로) |

채집한 자원이 주민·연구·군대로 바뀌고, 토벌과 전쟁의 보상(영토·희귀 자원·전투 경험치)이 다음 바퀴를 키운다. 진행은 두 축으로 측정한다: 왕국 등급(개척지 → 촌락 → 작은마을 → 중간마을 → 큰마을 → 소국 → 왕국 → 제국 → 대제국, 7장)과 기술 시대(중세 → 증기 → 산업 → 근대, 13장).

### 4-3. 순도 등급

티타늄과 텅스텐은 별도 정련 공정을 거쳐 3단계 순도를 갖고, 순수할수록 강하다. 이를 쓴 합금도 같은 순도 배율을 받는다.

| 순도 | 티타늄 공정 | 텅스텐 공정 | 성능 배율 | 수율 (초안) |
| --- | --- | --- | --- | --- |
| I 조정 | 염소화 + 환원로 → 스폰지 티타늄 | 분쇄·세광 + 용해 | ×1.0 | 100% |
| II 정련 | 진공 아크 재용해로 | 산 처리 화학 정련소 | ×1.35 | 70% |
| III 고순도 | 마력 부유 대역정제로 | 마력 수소환원로 | ×1.8 | 45% |

- **합금의 순도** = 투입한 티타늄·텅스텐 중 가장 낮은 등급. 오로라 합금 III는 두 금속 모두 III가 필요하다.
- **티타늄·텅스텐이 없는 합금**(마강, 다이아몬드+마석, 마철)은 마석 품질이 순도 역할을 한다: 탁한 = I, 맑은 = II, 순수·심연 = III.
- 순도 III(×1.8)는 한 순위 위 재료의 순도 I(×1.7)과 거의 같다. 자원이 부족할 때 ‘낮은 순위를 고순도로’ 만드는 선택지가 생긴다.
- 합금은 전용 설비에서만 만든다: 용광로(강철) → 마력 전기로(마석 합금) → 고온 마력로(텅스텐·티타늄 합금) → 공명 제련로(오로라 합금). 합금명·수치는 제안이며 모두 데이터 파일에서 조정한다.

## 5. 마석·마법진(반도체) 시스템

마석은 갈아서 분말로 만들고, 분말로 금속 기판에 회로를 새기면 마법진이 된다. 마법진의 세대가 곧 그 시대의 전자 기술 수준이다.

**가공 체인**: 마석 원석 → 분쇄기(맷돌 → 동력 분쇄기) → 마석 분말 → 회로 작업대에서 기판에 새김 → 마법진

**마석 품질**: 탁한(하급) → 맑은(중급) → 순수(상급) → 심연(최상급, 던전 보스 드랍). 분말 품질이 마법진·각인의 상한을 정한다.

| 세대 | 기판 | 현실 대응 | 가능한 것 |
| --- | --- | --- | --- |
| 1세대 단일 회로 | 구리판 | 스위치·전기 초기 | 조명, 점화, 문·피스톤 제어, 논리 게이트 |
| 2세대 복합 회로 | 은판 | 진공관 | 증폭, 무선통신, 공장 자동화, 반중력 Lv1 |
| 3세대 집적 회로 | 금판 | 초기 트랜지스터 | 사격통제, 탐지기(레이더급), 자동 포탑, 로봇 제어 |
| 4세대 적층 마법진 | 티타늄 틀 + 금 | 1950년대 이상 | 대형 반중력 코어, 제트 엔진 제어, 연산기 |

**마력망**: 마력로(마석 연소·공명) → 마력선(구리→은→금 케이블, 손실률 차등) → 장치. 블록으로 까는 전력망이며, 마법진 블록으로 레드스톤처럼 논리 회로(AND/OR/NOT/타이머)를 짤 수 있다.

**동력원 발전**: 초반 산업시설·전투기계는 석탄·석유를 태워 움직이고, 연구로 마력 배터리를 만들면 전기처럼 충전해 쓰는 동력원으로 넘어간다.

| 단계 | 동력원 | 방식 | 주 사용처 |
| --- | --- | --- | --- |
| 1 | 석탄 | 보일러·증기기관에 연료 직접 투입 | 공장, 증기 트랙터, 증기선, 철도 |
| 2 | 석유 | 정유 후 내연기관(디젤·가솔린) | 트럭, 전차, 프롭기, 발전기 |
| 3 | 마력 배터리 (연구) | 마석 + 구리·은 전극 + 마법진, 충전식·교체식 | 공장 자동화, 차량, 산업 로봇, 파워아머 |
| 4 | 고밀도 마력 셀 (후반 연구) | 순수·심연 마석 + 금 전극, 4세대 마법진 | 반중력 코어, 비행 전함, 제트기, 철관 보행기 |

- **배터리 능력치**: 용량, 출력, 충전 속도, 수명(충전 횟수). 마석 품질이 용량을, 전극 금속이 출력을 정한다.
- **충전**: 충전소에서 충전한다. 충전소의 전원은 석탄·석유 발전기 → 마력로 → 마력 공명로 순으로 발전하며, 공장은 마력선으로 직결할 수도 있다.
- **보급**: 배터리는 물건이라 교체팩을 전선으로 운송해야 한다. 전초기지 충전소 네트워크가 작전 범위를 정한다.
- **혼용**: 연료 기관 + 배터리를 함께 싣는 하이브리드 설계 가능. 연료는 항속거리, 배터리는 순간 출력·마력 장치 담당.
- 석탄·석유는 후반에도 제련·정유·수지 등 산업 원료로 계속 쓰인다.

**긴장 요소**: 과부하 시 장치 폭발, 마력을 많이 쓸수록 주변 ‘마력 오염’이 쌓여 몬스터 둥지 발생률이 오른다 (12장과 연결).

## 6. 각인(인챈트) 시스템

갑옷·검·총기·폭발물·작업 도구에 마석 분말로 문양을 새겨 효과를 붙인다. 필요한 것은 각인 전용 작업대(일반 작업대 불가), 마석 분말, 조각사(플레이어 또는 훈련된 주민)다.

**진행 방식**

1. **각인 전용 작업대**: 일반 작업대로는 각인할 수 없다. 제작비가 비싸고(초안: 강철 20, 금 10, 탁한 마석 8), 상위 작업대 II·III는 티타늄·상급 마법진이 더 필요하다. 높은 등급·특수 각인은 상위 작업대에서만 가능.
2. **진행**: 작업대에 장비 + 마석 분말 + 부재료를 넣고 연구로 해금한 문양을 고르면, 작업 시간이 지난 뒤 완성된다.&#32;
3. **결과**: 분말 등급이 각인 상한과 작업 시간을, 부재료가 효과 수치·부가 속성을 정한다.
4. **조각사**: 플레이어는 마력학 경험치, 주민은 숙련도·교육 수준이 성공률을 올리고 시간을 줄인다. 주민 조각사는 반복하며 성장한다.
5. **품질**: 일반 → 정예 → 걸작 (효과 수치 ×1.0 / ×1.3 / ×1.6 초안). 조각사 실력과 부재료가 확률을 정한다.

| 분말 등급 | 각인 레벨 | 작업 시간 (초안) |
| --- | --- | --- |
| 탁한 분말 | Lv1\~2 | 10\~15초 |
| 맑은 분말 | Lv3 | 30초 |
| 순수 분말 | Lv4\~5 | 60\~90초 |
| 심연 분말 | 특수 각인 | 5분 |

레벨별 분말 양·성공률·효과 수치는 ‘각인·주문 상세’ 탭에 있다.

**부재료 예시**: 은(대마물 피해), 금(마력 전도 → 효과 증폭), 다이아몬드 가루(치명타), 텅스텐 가루(관통), 몬스터 소재(독·화염 등 속성)

**슬롯과 비용**: 슬롯 수는 재료 등급이 정한다(4장 표). 같은 장비에 각인을 더할수록 분말 비용이 급증하고, 특수 각인은 심연 마석 분말과 던전 도안이 필요하다. 실패 시 분말이 사라지고, 특수 각인의 대실패는 장비 내구도를 깎는다.

| 분류 | 효과 예시 | 대상 |
| --- | --- | --- |
| 기본 | 공격력, 내구력, 방어력 | 전 장비 |
| 전투 | 범위 증가, 공격 속도, 관통, 연사 속도, 재장전 속도, 사거리 | 근접·총기 |
| 생존 | 체력 재생, 마력 보호막, 넉백 저항, 화염 저항 | 갑옷 |
| 폭발 | 폭발력, 폭발 범위, 파편, 소이 | 폭발물·포탄 |
| 작업 | 채굴 속도, 수확량, 건축 속도, 피로 감소 | 주민 작업 도구 |
| 특수 | 연쇄 번개, 중력 붕괴(폭발 후 흡인), 공간 도약 참격, 마력 흡수, 시간 지연 장, 원거리 참격파, 소형 특이점탄 | 최상급 장비 |

- 작업 도구 각인은 주민 생산성에 직접 반영되어, 조각사를 키우는 것 자체가 경제 전략이 된다.
- 특수 각인은 장비당 1개 제한.

## 7. 왕국·영토 확장

왕좌 블록을 설치하고 왕국을 선포하면 왕좌 중심 100×100 블록(높이 무제한)이 영토가 된다. 이후 자원을 투자해 청크(16×16) 단위로 계속 넓힌다.

- **선포**: 월드는 왕국이 없는 상태로 시작한다. 왕좌 + 주민 침대(초안 5개) + 거점(창고·작업대·화로)을 갖추면 왕좌에서 선포할 수 있고, 이때 왕국명·문장·깃발 색을 정한다. 다른 왕국 영토 안에서는 선포 불가.
- **확장**: 영토 경계에 접한 청크를 지도에서 선택해 구매. 비용은 현재 면적에 따라 증가(확장 비용 = 기본값 × (1 + 보유 청크 수 / 200), 상세는 경제 탭 초안). 초반엔 나무·돌, 이후 금·마석이 필요.
- **전초기지**: 떨어진 광맥·유전은 전초기지를 세워 별도 영토로 확보. 본토와 도로·철도로 연결하면 보급 보너스.
- **영토 효과**: 주민 작업·건축은 영토 안에서만 가능, 경비가 있으면 몬스터 스폰 억제, 타 왕국이 침범하면 관계 하락, 영토 내 자원에 세금.
- **법령**: 왕국 등급이 오를수록 법령 슬롯이 늘어난다. 예: 징병제, 배급제, 세율, 의무교육, 마력 통제법, 전시 동원령.

| 왕국 등급 | 주민 수 | 해금 (초안) |
| --- | --- | --- |
| 1 개척지 | 10 | 왕좌 선포, 기초 건축, 욕구 1단계 |
| 2 촌락 | 20 | 직업 분화, 행정부·재정부, 법령 1칸, 욕구 2단계 |
| 3 작은마을 | 80 | 학교, 상인·교역, 병영·징집, 장군 1명, 외교, 둥지 토벌 파견, 욕구 3단계 |
| 4 중간마을 | 160 | 국방부·과학기술부·마력부, 고등학교·대학, 경호부대(분대), 법령 2칸 |
| 5 큰마을 | 300 | 부당 청 1개, 조직 자동 운영, 장군 2명, 두 번째 도시 |
| 6 소국 | 600 | 재상, 대학원, 경호부대(중대), 법령 3칸, 욕구 4단계 |
| 7 왕국 | 1,000 | 부당 청 2개, 장군 5명, 속국 보유, 욕구 5단계, 법령 4칸 |
| 8 제국 | 5,000 | 부당 청 3개, 장군 10명, 경호부대(대대), 법령 5칸 |
| 9 대제국 | 10,000 | 근위대(연대급), 장군 무제한, 법령 6칸, 제국 칙령(특수 법령) |

등급 이름은 규모를 나타낼 뿐, 게임 안 국호는 플레이어가 선포한 이름을 그대로 쓴다. 등급이 오르려면 주민 수와 함께 행복도 평균이 일정 이상이어야 한다(초안). 선포 직후 주민이 10명 미만인 동안은 등급 없는 ‘거점’ 상태다.

### 정부 조직

플레이어는 5개 부의 장관을 주민 중에서 임명한다. 자격은 해당 분야 경험치(숙련도)가 기준 이상이거나 학사 이상인 주민(관련 전공 우대: 행정부 = 법·행정학, 재정부 = 경제학, 국방부 = 군사학, 과학기술부 = 과학·공학, 마력부 = 마력학)이며, 장관의 실력이 높을수록 부의 보너스가 커진다.

| 부 | 담당 보너스 (초안) | 하위 청 예시 |
| --- | --- | --- |
| 행정부 | 건축 속도, 치안·행복도, 영토 확장 비용 감소 | 건설청, 치안청, 도시계획청 |
| 재정부 | 세수, 교역 이익, 자원 유지비 감소 | 조세청, 관세청, 조폐청 |
| 국방부 | 징집 효율, 훈련 속도, 보급 효율 | 병무청, 병창청(군수품), 항공청 |
| 과학기술부 | 연구 속도(RP), 교육 효율 | 교육청, 연구개발청, 특허청 |
| 마력부 | 마석 가공·마력망 효율, 각인 성공률·시간, 마력 오염 억제 | 마석관리청, 마력망청, 각인청 |

- 청장도 같은 기준으로 임명하며, 청은 부보다 좌은 분야에 더 큰 보너스를 준다 (예: 병무청 = 징집 속도·징집 후 생산 하락 감소).
- **재상(국무총리 역할**): 모든 부 보너스를 일부 증폭하고, 플레이어가 자리를 비울 때 내정을 자동 처리한다.
- **왕 직속 경호부대**: 레벨 높은 병사 중 선발되는 정예 부대. 플레이어를 따라다니며 최고급 장비를 우선 배정받는다.

**조직 자동 운영**: 큰마을 등급부터 각 부·청은 직원(공무원)을 두고 스스로 유지된다. 장관·청장이 자격을 갖춘 주민을 신입으로 뽑고 결원을 보충하며, 맡은 업무(예: 병무청의 징집 관리, 교육청의 입학 배정, 조세청의 세금 징수)를 자동으로 처리한다. 플레이어는 방침(우선순위·예산·법령)만 정하면 된다. 직원 수는 주민의 약 2\~4%(초안).

## 8. 주민·욕구·생산·건축

주민은 욕구가 채워져야 일하고, 왕국이 커질수록 욕구의 종류가 늘어난다. 욕구 미충족 → 행복도 하락 → 생산성 하락 → 작업 태만까지만 간다. 주민 반란과 이탈은 없다.

**주민 속성**: 이름, 직업, 직업별 숙련도, 교육 수준(1\~7)·전공 학위, 행복도, 충성도, 건강, 장비, 특성(부지런함·겁쟁이 등)

| 욕구 단계 | 해금 시점 | 추가되는 욕구 |
| --- | --- | --- |
| 1 생존 | 개척지 | 음식, 집(침대), 잠 |
| 2 안정 | 촌락 | 깨끗한 물·위생, 의복, 치안(경비) |
| 3 공동체 | 작은마을 | 신앙(제단), 여가(선술집), 다양한 음식 |
| 4 산업 | 소국 + 산업화 연구 | 생필품(비누·가구·도구), 의료, 교육 |
| 5 근대 | 왕국 + 마력망 | 마력 조명, 교통, 오락(극장·라디오), 사치품 |

**직업**: 농부, 어부, 사냥꾼, 벌목꾼, 광부, 제련공, 대장장이, 조각사, 건축가, 요리사, 재단사, 연구원, 교사, 의사, 기계공, 운전사·조종사, 상인, 병사

**생산 체인 예시**

- 밀 → 제분소 → 빵집 → 빵
- 철광석 + 석탄 → 용광로 → 강철 → 대장간 → 도구·무기
- 목화·양모 → 방적소 → 재단소 → 의복
- 원유 → 정유소 → 연료·고무·수지 → 차량·생필품

**교육·훈련**: 교육은 7단계이고, 학사·석사·박사는 전공별로 따로 받는다. 한 주민이 여러 전공의 학위를 가질 수 있다.

| 단계 | 기간 (게임일, 초안) | 시설 | 효과 |
| --- | --- | --- | --- |
| 1 무학 | — | — | 없음 |
| 2 초등 | 2 | 학교 | 생산 +5% |
| 3 중등 | 2 | 학교 | 생산 +10%, 연구 +8% |
| 4 고등 | 2 | 고등학교 | 생산 +15%, 연구 +15%, 기술직 가능 |
| 5 학사 | 4 | 대학 (전공 학과) | 전공 분야 생산·연구 +25%, 장관·청장 자격 |
| 6 석사 | 4 | 대학원 | 전공 분야 +45%, 대학 교수 자격 |
| 7 박사 | 6 | 대학원 | 전공 분야 +70%, 수석 연구원(분야 최종 연구에 필요) |

- **전공 10개**: 마력학, 공학, 농업학, 과학, 군사학, 경제학, 의학, 법·행정학, 교육학, 건축학. 전공마다 학사 → 석사 → 박사 순서.
- **전공 매칭**: 학위 보너스는 전공과 맞는 일에만 붙는다 (농업학 → 농부, 의학 → 의사, 군사학 → 장교·장군, 교육학 → 교사, 건축학 → 건축가, 마력학 → 조각사·마도사 등).
- **의무교육 법령**: 초등 / 중등 / 고등 / 대학(학사)까지 설정한다. 아이는 의무교육을 마쳐야 일을 시작하므로, 길게 잡을수록 노동력은 늦게 들어오지만 인재 수준이 올라간다. 성인은 일을 쉬고 학교에 다니도록 지시할 수 있다.
- **정원**: 교사 1명당 학생 10명. 대학·대학원은 해당 전공 석사 이상의 교수가 있어야 그 학과가 열린다.
- 직업 숙련도는 교육과 별개로 일하며 오른다.

**건축**: 모든 건물은 기본 디자인(청사진)으로 지어지고, 플레이어는 완공 후 또는 짓기 전에 모양을 꾸미거나 구조를 바꿀 수 있다. 기능은 ‘필수 조건’만 지키면 유지된다.

| 바꾸는 것 | 예시 | 결과 |
| --- | --- | --- |
| 꾸미기 | 벽·지붕 재질 교체, 창문·장식 블록·조명·화분 추가 | 기능 그대로, 미관 점수 상승 |
| 구조 변경 | 방·층 추가, 벽 이동, 입구 위치 변경 | 넓어진 만큼 수용·작업 자리 증가 |
| 기능 블록 추가 | 대장간에 모루 추가, 주택에 침대 추가 | 동시 작업자·거주 인원 증가 (건물별 상한 있음) |

- **필수 조건**: 핵심 기능 블록, 최소 내부 면적, 출입구 1개 이상, 지붕(실내 판정), 필수 가구(예: 학교 = 책상 10 + 칠판). 조건이 깨지면 건물이 ‘비활성’이 되고 건물 위에 경고가 뜬다.
- **편집 방법**: 직접 블록을 놓고 부수거나, 청사진 편집기에서 반투명 블록으로 고친 뒤 주민에게 시공을 맡긴다. 바뀐 부분만 자재가 들고, 철거한 블록은 70%를 돌려받는다.
- **내 청사진**: 고친 건물은 새 청사진으로 저장해 다른 곳에 그대로 짓거나, 그 건물의 기본 디자인으로 지정할 수 있다.
- **건축 양식**: 왕국 양식(목조 → 고딕 석조 → 산업 벽돌 → 마력 첨탑)을 고르면 새 건물의 기본 디자인이 바뀐다. 건축학 박사 건축가가 있으면 양식을 섞은 ‘왕국 고유 양식’을 만들 수 있다.
- **미관 점수**: 장식 블록의 다양성·조명·녹지로 계산하며, 반경 16블록 안 주민의 행복도를 +1\~+10 올린다.

예시: 기본 주택(7×7, 침대 4)에 2층을 올리고 침대를 4개 더 놓으면 가정 2개가 산다. 지붕을 청동판으로, 창을 장미창으로 바꾸고 화분을 두면 미관 점수가 올라 이웃 주민들의 행복도도 오른다. 대장간은 모루를 3개까지 늘려 대장장이 3명이 동시에 일하게 할 수 있다.

**주민 AI**: 욕구 점수 기반 유틸리티 AI + 작업 게시판(job board) + 복셀 경로탐색(계층형 A\*).

**성향**: 부지런함·게으름·학구적·호전적·손재주 등. 성향에 따라 직업별 생산량이 달라지고, 싫어하는 일에 배정하면 생산량이 줄어든다.

**인구 증가·사망**: 주민은 늙거나 자연사하지 않는다. 죽는 것은 사고(추락·화재·폭발·익사·붕괴)와 전투·습격뿐이다.

- **이주**(주 경로): 빈 침대가 있으면 왕국 매력도(음식·행복도·치안·명성)에 따라 방랑민이 찾아온다. 가끔 숙련도·교육 수준이 높은 인재가 온다.
- **출생**: 가정과 여유 주택이 있으면 아이가 태어난다. 출생 빈도는 행복도·음식 여유에 비례한다. 아이는 일하지 않고 학교에 다니며, 일정 시간 뒤 성인이 되면 그 뒤로는 늙지 않는다. 어릴 때 교육을 받으면 교육 수준이 높은 성인이 된다.
- **흡수**: 합병한 왕국의 주민, 던전·둥지에서 구출한 사람
- **부상**: 중상을 입은 주민·병사는 의무실·병원에서 치료해야 복귀한다. 오래 방치하면 사망(제안).

## 9. 군사: 징집·병종·장군·전술

군대는 주민을 징집해 만들기 때문에, 병력을 늘리면 생산이 줄어드는 것이 핵심 트레이드오프다.

- **징집**: 병영에서 주민을 병사로 전환. 징병 법령에 따라 상한(주민의 10% → 총동원 시 40%) 조절. 과도한 징집은 행복도·생산 감소.
- **편제**: 분대(8명) → 소대(4분대) → 중대 → 대대. 진형(횡대·종대·방진·산개)과 명령(이동·공격·방어·순찰·매복·약탈·공성).
- **보급·사기**: 병사는 식량·탄약을 소모하고 보급선(마차→트럭→수송기)이 끊기면 약화. 사기 0이면 패주.

| 병종 | 역할 | 해금 (기술 트리) |
| --- | --- | --- |
| 창병·검병 | 근접 전열 | 병영 (작은마을) |
| 궁수 → 석궁병 → 소총병 | 원거리 주력 | 병영 → MIL-2 → MIL-4 |
| 기관총 사수 | 제압 사격 | MIL-5 |
| 척탄병 | 폭발물·방어선 돌파 | MIL-3 |
| 마도사 | 마법 공격·보호막·치유 | MAG-3 |
| 공병 | 참호·다리·폭파·수리 | IND-1 |
| 의무병 | 치료·후송 | LIF-4 |
| 포병 | 대포 → 박격포·야포 | MIL-3 → MIL-6 |
| 중장갑 보병 | 마력 파워아머 정예 | MIL-9 |
| 기갑·조종·해병 | 차량·항공기·함선 운용 | MIL-7 / TRN-6 / TRN-3 |

**장군**: 주민 중 임명. 전투로 경험치를 얻고 레벨이 오르면 특성 포인트를 받는다.

- 지형 특화: 숲, 산악, 사막, 설원, 습지, 해상, 공중, 지하(던전)
- 병종 특화: 보병, 기갑, 포병, 마도, 항공, 해군
- 공통: 지휘 범위, 사기 오라, 보급 효율, 후퇴 시 손실 감소
- 장군이 전사하면 경험치의 일부만 후임에게 승계

**전략·전술 버프**: 전투로 쌓이는 전투 경험치(CXP)로 연구한다. 예: 방진 훈련(근접 방어↑), 제압 사격(적 이동↓), 협동 포격, 야간 기습, 마력 결계 전개, 보병-전차 협동, 급강하 강습.

## 10. 탈것·전쟁기계

모든 탈것은 ‘조립식 설계대’에서 차체·엔진·무장·장갑·마법진 슬롯을 조합해 만든다. 부품 재료의 등급(4장)과 각인이 성능에 그대로 반영된다.

| 분류 | 발전 단계 |
| --- | --- |
| 지상 | 마차 → 증기 트랙터 → 디젤 트럭 → 장갑차 → 경·중형 전차 → 중전차·구축전차·자주포 → 마력 초중전차 |
| 해상 | 뗏목·범선 → 증기선 → 구축함·순양함 → 전함 → 항공모함 |
| 항공 | 열기구·비행선 → 복엽 프롭기 → 단엽 전투기·폭격기 → 비행 전함 → 비행 항공모함 → (극후반) 제트기 |
| 로봇 | 산업용 보행기(채굴·운반·건설) → 탑승형 전투 보행기 → 자율 로봇(3세대 마법진) |

**반중력 장치**: 마석으로 기체 무게를 줄이고, 연구할수록 더 큰 덩치를 띄운다. 마력을 계속 소모하며, 마력이 끊기면 추락한다.

| 단계 | 무게 감소 (초안) | 띄울 수 있는 것 |
| --- | --- | --- |
| Lv1 | −20% | 소형기 성능 향상 |
| Lv2 | −50% | 대형 폭격기, 무장 비행선 |
| Lv3 | −80% | 구축함급 비행함 |
| Lv4 | −95% | 전함·항공모함급 비행함 |

- **프롭기가 기본**, 제트기는 제트 엔진 + 4세대 마법진 + 고온 합금 + 대규모 공장이 모두 필요한 최종 연구.
- **철관 보행기**: 관 모양 몸체 안에 조종사가 탑승하는 중장갑 전투 로봇. 팔 무장 교체식(대형 전기톱, 화염방사기, 마력포).
- **구현 방침**: 1차는 부품 조합형 사전 모델 + 강체 물리. 플레이어가 블록으로 직접 지은 함선을 움직이는 방식은 후속 확장으로 미룬다 (29장 리스크).

## 11. AI 왕국: 외교·전쟁·복속·약탈

월드 생성 시 고정 AI 세력 6개와 무작위 소왕국 0\~4개가 배치되고, 플레이어와 같은 규칙(자원·주민·연구·군대)으로 성장한다. 플레이어에게서 멀리 있는 왕국은 블록 단위가 아닌 수치로 추상 시뮬레이션해 성능을 지킨다.

**외교**: 관계도 −100\~+100. 행동은 교역 협정, 불가침, 동맹, 기술 교류, 조공 요구, 선전포고, 평화 협상. 교역은 상단(마차·배·비행선)이 실제로 이동하므로 호위하거나 약탈할 수 있다.

| 전쟁 결과 | 방식 | 얻는 것 | 대가 |
| --- | --- | --- | --- |
| 복속 | 적 왕좌 점령 후 속국화 | 정기 조공, 병력 제공 | 관계가 나쁘면 조공·병력 지연 |
| 합병 | 왕좌 점령 후 편입 | 영토·주민·건물 | 피정복민 불만(행복도↓) |
| 약탈 | 창고·상단 급습 | 자원 즉시 획득 | 관계 하락 |
| 파괴 | 도시·시설 파괴 | 적 국력 약화 | 타 왕국 전체 평판 하락 |

**AI 구조 (3층)**

1. 전략층: 왕국 목표(확장·교역·연구·정복) 선택, 성향(2장 표)에 따라 가중치가 다름
2. 작전층: 군 편성, 침공 경로, 방어 거점 결정
3. 전술층: 개별 부대 전투 (엄폐, 집중 사격, 후퇴)

AI 중 가장 강한 제국은 아시리아이며, 아시리아를 파괴하거나 복속하는 것이 승리 조건이다(18장). AI의 강함은 난이도와 관계없이 같다.

## 12. 몬스터 둥지·던전

둥지는 방치하면 자라서 영토를 습격하므로 주기적으로 토벌해야 하고, 던전은 희귀 자원의 핵심 공급원이다.

- **둥지 성장**: 1\~5단계. 일정 시간마다 한 단계씩 오르고, 3단계부터 주변 왕국에 습격 이벤트를 일으킨다. 마력 오염이 높은 지역은 둥지가 더 자주 생긴다.
- **토벌 방식**: 직접 토벌 / 부대 파견(실시간 전투) / 장군 원정(자동 해결: 전력 비교로 승패·손실 계산). 토벌은 전투 경험치의 주요 공급원.
- **던전**: 절차생성 방 + 고정 보스방, 여러 층 구조. 보상은 심연 마석, 티타늄 등 희귀 광석, 특수 각인 도안, 고대 유물(연구 해금).

| 둥지 | 서식지 | 특징 |
| --- | --- | --- |
| 마독 늑대굴 | 숲 | 빠른 무리 사냥, 야간 습격 |
| 거미 여왕 둥지 | 울창한 숲·동굴 | 거미줄 함정, 독 |
| 오우거 야영지 | 산악 | 소수 거구, 건물 파괴 |
| 변이 곤충 군락 | 습지·마력 오염지 | 대규모 물량, 번식 빠름 |
| 망령 묘지 | 폐허·능선 | 마법 공격, 은 무기에 약함 |
| 마력 거수 둥지 | 마력 지대 심부 | 보스급, 심연 마석 드랍 |

## 13. 연구·기술 트리

연구는 세 가지 포인트로 진행하고, 종점은 1950년대 기술 + 마석으로 확장된 고유 기술이다.

| 포인트 | 얻는 법 | 쓰는 곳 |
| --- | --- | --- |
| 연구점(RP) | 연구소의 주민 연구원 (교육 수준·장비 각인 반영) | 모든 트리 |
| 개인 경험치(XP) | 플레이어의 행동 (채굴→공학, 마법 사용→마력학, 제작→산업) | 해당 분야 트리, 연구 가속 |
| 전투 경험치(CXP) | 전투·토벌·전쟁 | 전략·전술 트리, 장군 성장 |

| 분야 | 중세 (\~300 RP) | 증기 (400\~1,500) | 산업 (2,000\~8,000) | 근대 (10,000\~, \~1950) |
| --- | --- | --- | --- | --- |
| 산업·공학 | 대장간, 용광로, 수차·풍차 | 증기기관, 공작기계 | 고온 마력로, 내연기관·정유, 조립 라인 | 산업 로봇, 공명 제련로 |
| 마력학 | 마석 분쇄, 기초 각인 | 1세대 마법진, 마력로·마력망 | 2\~3세대 마법진, 마력 배터리, 반중력 Lv1\~2, 오염 정화 | 고밀도 마력 셀, 4세대 마법진, 반중력 Lv3\~4, 특수 각인, 의식 마법 |
| 군사·무기 | 판금 갑옷, 석궁 | 화약(머스킷·대포·수류탄), 강선 소총 | 기관총, 야포·박격포, 장갑차, 파워아머 Mk I | 전차 계열, 파워아머 Mk II·III, 철관 보행기, 로켓, 마력·공명 폭약 |
| 교통 | 마차·도로, 범선 | 증기선·철도 | 비행선, 트럭, 복엽 프롭기 | 단엽기, 구축함\~항모, 비행 전함·항모, 제트기 |
| 농업·생활 | 윤작, 제분·제빵, 위생 | 의료 I, 비료 | 생필품 공장, 의료 II, 통조림, 마력 조명 | 라디오·극장 |
| 사회·통치 | 법령, 화폐, 학교 | 관료제 | 고등학교·대학, 징병제, 속국 체계 | 총동원, 대학원 |
| 전략·전술 (CXP) | 방진, 돌격 | 산개, 포격 지원 | 제압 사격, 보병-전차 협동 | 입체전, 급강하 강습 |

시대 구분은 기술 트리 탭의 노드 비용 범위와 일치한다.

- 트리 데이터는 모두 외부 파일(JSON)로 관리해 선행 조건·비용을 코드 수정 없이 바꾼다.
- 던전 유물은 일부 연구를 건너뛰게 해준다.

## 14. 전투·애니메이션

목표는 Actions & Stuff처럼 각진 블록 모델이지만 무게감·관성이 살아 있는 모션이다. 해당 팩의 에셋은 쓰지 않고 느낌만 참고해 자체 제작한다.

**구현 방식**: 큐보이드 파트 계층(머리·몸통·팔다리 2관절) + 키프레임 애니메이션(이징 곡선) + 절차적 레이어를 상태머신으로 블렌딩한다.

- 절차 레이어: 호흡, 발걸음 흔들림, 스프링 2차 모션(망토·장식), 발 IK, 조준 방향 상체 회전
- 1인칭 손: 휘두르기, 채굴, 먹기, 블록 설치, 재장전, 검사(inspect) 모션
- 근접: 3단 콤보, 차지 강공격, 막기·패링, 회피 구르기, 히트스톱(일반 0.05초, 강타 0.10초), 화면 흔들림, 타격 파티클
- 총기: 볼트 조작, 탄창 교체, 반동 패턴, 탄피 배출, 총구 화염 + 마력 발광
- 폭발: 반경×폭발력으로 블록 파괴, 파편 입자, 충격파 왜곡(쉐이더), 연기
- 주민·병사도 같은 시스템을 쓰되, 멀리 있으면 애니메이션 갱신 빈도를 낮춰 수백 명을 처리

**애니메이션 제작 우선순위**: 걷기·달리기·점프 → 채굴·설치 → 근접 콤보 → 총기 → 주민 작업 모션 → 몬스터 → 탈것 탑승 → 보행기

## 15. 그래픽·쉐이더

쉐이더는 기본 탑재이며, 목표는 GTX 1060급 GPU에서 1080p·60fps·렌더거리 16청크(‘중간’ 프리셋)다.

**효과**: 계단식 그림자(CSM 3단), 경량 SSAO, 높이 안개·대기 산란 근사, 마력 발광 블룸, ACES 톤매핑, 물 반사(하늘 + 간이 SSR), 흔들리는 잎·풀, 낮밤·구름, 폭발 충격파 왜곡

## 17. 월드 생성·날씨

월드는 가로·세로 ±30,000,000 블록(마인크래프트와 같은 크기)이고, 높이는 y −50\~300이다. 플레이어가 가는 곳만 청크 단위로 그때그때 생성한다.

- **크기 구현**: 청크 좌표는 정수, 렌더링은 카메라 기준 상대 좌표로 처리해 먼 좌표에서도 떨림이 없게 한다.
- **높이**: y −50에 파괴 불가 기반암, y 300이 건축 한계. 해수면은 y 63(제안). 청크는 16×16 기둥을 16층 단위 섹션 22개로 나눈다.
- **시드**: 같은 시드는 같은 월드. 생성 옵션은 AI 왕국 수, 시작 바이옴 정도만 둔다.

| 높이 구간 | 주요 자원 |
| --- | --- |
| y 64\~300 (지표·산악) | 나무, 돌, 노출 석탄·구리, 산악 텅스텐 |
| y 0\~63 (얕은 지하) | 석탄, 구리, 철, 탁한 마석 |
| y −30\~0 (깊은 지하) | 금, 은, 텅스텐, 다이아몬드, 맑은 마석 |
| y −49\~−30 (최심층) | 티타늄, 다이아몬드, 순수 마석, 용암호 |

| 바이옴 | 특징 | 특산·위협 |
| --- | --- | --- |
| 평원 | 넓고 평평, 시작에 좋음 | 농업, 방랑민 야영지 |
| 숲 | 목재 풍부 | 마독 늑대굴 |
| 마력 숲 | 발광하는 나무, 몬스터 많음 | 지표 마석, 거미 둥지 |
| 침엽수림·설원 | 추위, 눈 | 모피, 이동 느림 |
| 산악 | 험준, 높이 260 안팎 | 텅스텐, 오우거 야영지 |
| 화산 지대 | 용암, 검은 돌 | 티타늄 |

- **구조물**: 방랑민 야영지, 유적, 던전 입구, 몬스터 둥지, AI 왕국 도시
- **AI 배치**: 스폰 근처에는 AI 왕국이 없고, 약한 왕국이 중간 거리에, 아시리아 제국은 가장 멀리(수천 블록) 배치한다.

**날씨·계절**: 계절은 만들지 않는다(농사·구현이 번거로워지는 데 비해 재미가 적다). 날씨는 분위기용으로 가볍게 넣는다.

- 바이옴별 날씨: 맑음, 비, 뇌우, 눈(설원), 모래폭풍(사막)
- 효과는 약하게: 비·눈·모래폭풍은 시야와 항공 명중률 조금 하락, 뇌우의 낙뢰는 마력 장치 과부하를 일으킬 수 있음
- 마력 폭풍은 날씨가 아니라 이벤트로 다룬다(21장).

## 18. 생존·난이도·승리 조건

플레이어는 죽어도 부활하고(일반), 승리는 최강 AI 제국 아시리아를 파괴하거나 복속하는 것이며, 승리 후에도 게임은 계속된다.

**플레이어 사망**

- 왕좌(또는 지정한 침대)에서 부활한다. 왕국 선포 전에는 처음 스폰 지점에서 부활.
- 인벤토리 아이템과 착용 중인 갑옷·무기가 모두 죽은 자리에 떨어진다. 레벨·경험치·연구·왕국은 그대로.
- 떨어진 아이템은 오래 남고(제안: 게임 시간 3일 = 90분), 병사·경호부대에게 회수를 명령할 수 있다.

| 난이도 | 규칙 |
| --- | --- |
| 일반 | 죽으면 부활, 계속 플레이 |
| 하드코어 | 한 번 죽으면 게임 끝, 월드 삭제 |

난이도는 월드 생성 때 정하고 바꿀 수 없다. 두 난이도에서 AI·몬스터의 강함은 같다.

**멀티플레이에서**: 서버의 난이도를 따른다. 하드코어 서버에서 죽은 플레이어는 관전자가 되고, 그 왕국은 주인 없는 왕국이 되어 AI가 관리한다(다른 플레이어가 정복할 수 있음). 월드는 삭제되지 않고 서버가 닫힐 때까지 유지된다. 멀티에는 일시정지가 없다.

**승리 조건 — 아시리아 제국**

- 월드에서 가장 강한 AI 제국. 처음부터 대제국 등급이고 병력·기술이 가장 앞서며, 스스로도 성장·침공한다.
- **파괴 승리**: 아시리아의 모든 도시와 왕좌를 파괴
- **복속 승리**: 수도 왕좌를 점령하고 속국으로 만듦
- 승리 시 연출과 통계 화면(플레이 시간, 최대 주민 수, 전투 기록)을 보여주고, 이후에도 다른 AI 제국과의 전쟁 등 모든 콘텐츠를 계속 즐길 수 있다.

## 19. 조작·UI

기본은 1인칭 영웅 플레이이고, 왕국 관리와 대규모 지휘는 ‘전략 지도 모드’로 전환해서 한다.

| 모드 | 시점 | 하는 일 |
| --- | --- | --- |
| 영웅 모드 | 1인칭 / 3인칭 | 채집·건축·전투·탑승, 지휘 휠로 근처 부대에 간단한 명령 |
| 전략 지도 모드 | 위에서 내려다보는 카메라 | 부대 선택·이동·공격, 청사진 배치, 영토 확장, 전선 확인 |
| 관리 창 | 화면 위 창 | 개요, 주민, 생산, 연구, 군사, 외교, 정부 탭 |

- **전략 지도 모드**: 싱글에서는 열면 게임 시간이 느려지고(×0.25) 일반 난이도에서는 일시정지도 된다. 멀티에서는 시간이 그대로 흐른다. 대신 왕좌나 지휘 탁자(요새·전초기지에 설치) 근처에서 열면 몸이 안전한 실내로 들어가 보호되고, 그 밖에서 열면 몸이 그 자리에 남아 공격받을 수 있다.
- **지휘 휠**: 키를 누르고 있으면 원형 메뉴(따라와 / 여기 공격 / 여기 방어 / 정지 / 회수)
- **HUD**: 체력, 마력, 탄약, 미니맵, 왕국 요약(주민·식량·행복도), 알림(습격·완공·연구 완료)
- **탈것 조작**: 차량·함선·항공기·보행기는 각자 전용 조작 + 탑승 중 무장 전환
- **키 설정**: 모든 키는 변경 가능. 패드는 후순위

## 20. 경제

왕국 안의 물자는 공동 창고에서 배급하고, 화폐는 대외 거래와 국가 지출에 쓴다. 주민 개개인의 지갑은 만들지 않는다.

- **물자(창고)**: 주민이 생산한 것은 창고로 들어가고, 음식·생필품은 욕구에 따라 자동 배급된다. 창고가 여러 곳이면 운반이 필요하다.
- **화폐(국고)**: 동화·은화·금화. 촌락 등급부터 조폐소에서 구리·은·금으로 주조한다. 그 전에는 물물교환.

| 국고 수입 | 국고 지출 |
| --- | --- |
| 세금 (주민 수 × 세율 × 행복도) | AI 왕국에서 물자 구매 |
| 교역 판매 | 영토 확장 비용 일부 |
| 조공 (속국) | 숙련 이주민·용병 고용 |
| 약탈·전리품 | 외교(협정 체결 비용, 배상금) |
| 주조 (금·은 채굴) | 시설 유지비, 군 유지비 |

- **세율 법령**: 높이면 수입↑ 행복도↓. 재정부 장관 실력이 세수를 늘린다.
- **시장 가격**: AI 왕국마다 시장이 있고, 가격은 그 왕국의 수요·공급으로 변한다. 전쟁 중인 왕국은 무기·식량을 비싸게 산다.
- **교역로**: 상단이 도로·바다·하늘로 실제 이동한다. 거리가 멀수록 이익이 크고, 몬스터·적 약탈 위험도 커진다.
- **사치품 상점**: 욕구 5단계 사치품은 국내 생산 또는 수입으로 채운다.

| 외교 제안 | 외교 | AI의 동맹·교역·혼인 제안, 조공 요구, 선전포고 |

- 위협 이벤트는 미리 경보를 준다(제안: 약 5분 전). 정찰대·탐지기가 있으면 더 일찍.

## 22. 첫 30분 플레이 흐름

목표는 30분 안에 왕국을 선포하고 첫 주민이 일하는 모습을 보는 것이다. 이 흐름이 P1\~P2 빌드의 검수 기준이다.

1. **0\~5분**: 평원·숲 경계에 스폰, 왕국 없음. 나무·돌 채집, 기본 작업대·도구.
2. **5\~10분**: 근처에 방랑민 야영지 발견(스폰 근처에 반드시 생성). 대화로 ‘왕좌와 잠자리가 있는 곳이면 따라가겠다’는 목표를 제시.
3. **10\~18분**: 거점 제작 — 창고·화로·침대 5개, 왕좌(나무·돌·철 약간). 20분에 첫 밤이 오므로 그 전에 벽과 조명이 필요.
4. **18\~20분**: 왕좌에서 왕국 선포 → 100×100 영토가 표시되고 방랑민 5명이 이주.
5. **20\~25분**: 주민에게 벌목·채석·농사를 배정, 청사진으로 첫 집을 짓게 함.
6. **25\~30분**: 밤에 작은 늑대 무리가 영토를 습격 → 플레이어가 직접 싸움. 이후 둥지 위치가 지도에 표시되어 다음 목표가 된다.

튜토리얼은 별도 모드 없이 이 흐름 위에 화면 구석의 목표 안내로 넣고, 끌 수 있다.

## 23. 사운드·모드·멀티플레이

- **효과음**: 타격·총성·폭발·기계음은 무게감이 핵심. 절차 생성 + CC0 자료로 시작하고, 거리·동굴 잔향을 적용한다.
- **음악**: 상황별(평화·전투·던전·아시리아 전쟁)로 자연스럽게 전환. 개발 후반(P6) 작업.
- **모드**: 블록·아이템·레시피·연구·각인·합금이 모두 JSON이므로, 데이터 폴더를 추가하는 것만으로 내용 추가가 된다. 스크립트 모드(Lua 등)는 출시 뒤 검토.
- **멀티플레이**: 향후 구현 확정. 출시는 싱글로 하고 멀티는 P7에서 붙이지만, 싱글도 내장 서버에 접속하는 서버-클라이언트 구조로 P0부터 만든다(마인크래프트와 같은 방식). 플레이어마다 각자의 왕국을 갖는다. 플레이어 왕국끼리도 AI 세력과 같은 외교 규칙(관계도·협정·전쟁 점수)으로 교역하거나 싸울 수 있고, 시작 지점은 서로 2,000블록 이상 떨어뜨린다. 아시리아를 먼저 무너뜨린 플레이어가 승리하고, 복속 승리라면 아시리아는 그 플레이어의 속국이 된다. 아시리아의 행동 단계는 플레이어 왕국마다 따로 계산하고, 원정군은 군사력이 가장 강한 플레이어 왕국부터 향하며 규모도 그 왕국 기준으로 정한다.

## 24. 시간·체력·전투 밸런스

하루는 30분(낮 20분·밤 10분), 체력은 마인크래프트식이고, 적의 강함은 7개 위협 등급으로 나눠 합금 순위와 1:1로 맞춘다.

**시간**: 1일 = 30분 = 36,000틱(20틱/초). 낮 20분, 밤 10분. 밤에는 몬스터 스폰이 늘고 주민은 잔다(야간 교대 법령을 두면 조명 있는 시설만 가동). 작물·연구·둥지 성장은 게임일 단위로 계산한다.

**체력 (마인크래프트식)**

- 플레이어: 체력 20(하트 10), 배고픔 20 + 포만감. 배고픔 18 이상이면 자연 회복, 0이면 체력이 줄어든다. 레벨로 최대 체력 40까지(25장).
- 주민·병사: 체력 20, 병사는 레벨로 최대 30.
- 갑옷 기본 방어 점수(강철): 투구 2 · 갑옷 5 · 각반 4 · 장갑 2 · 신발 2 = 15. 여기에 재료 방어 배율·순도·각인을 곱한다.

```latex
\text{피해} = \text{무기 기본 피해} \times \text{재료 공격 배율} \times \text{순도} \times \text{각인} \qquad \text{받는 피해} = \text{피해} \times \frac{20}{20 + \text{방어}}
```

검의 기본 피해는 8이다(나무 3.2, 돌 4, 철 6, 강철 8, 오로라 합금 I 114). 위협 등급이 하나 오를 때마다 적 체력은 ×1.7, 공격은 ×1.55다.

| 위협 등급 | 대응 장비 | 적 체력 | 적 공격 | 주로 나오는 곳 |
| --- | --- | --- | --- | --- |
| T1 | 하위 (나무\~철) | 20 | 3 | 스폰 반경 1,000블록 지표 |
| T2 | 6위 (강철 등) | 34 | 5 | 1,000\~3,000블록, 얕은 지하, 밤 |
| T3 | 5위 (마강 등) | 58 | 7 | 3,000\~8,000블록, 깊은 지하, 둥지 3단계 |
| T4 | 4위 | 98 | 11 | 8,000블록 이상, 마력 숲·산악, 던전 상층 |
| T5 | 3위 | 167 | 17 | 마력 결정 평원, 최심층, 던전 중층 |
| T6 | 2위 | 284 | 27 | 던전 심층, 아시리아 변경 |
| T7 | 1위 | 482 | 42 | 아시리아 본토, 던전 최하층 |

- **목표 손맛**: 같은 등급 장비면 일반 적을 약 4번에 잡고, 약 9\~12번 맞아야 죽는다. 한 등급 낮은 장비면 약 7번 쳐야 하고 약 7번 맞으면 죽는다. (위 공식으로 계산, 플레이어 체력은 등급에 따라 20→40 가정)
- **정예·보스**: 정예는 체력 ×1.5, 보스는 체력 ×10·공격 ×1.5.
- **총기**: 소총 한 발은 같은 재료 검의 1.5배, 연사 무기는 발당 0.4배. 대신 탄약을 소모한다.
- **폭발·대물 무기**: 방어를 절반만 적용(관통). 차량·함선·보행기 장갑은 폭발·대물 무기로만 제대로 뚫는다.
- **군대끼리 전투**: 병사도 같은 공식. AI 군대의 장비는 그 왕국의 기술 시대를 따른다.
- 모든 수치는 데이터 파일로 빼서 플레이테스트로 조정한다.

## 25. 플레이어 성장

왕은 레벨 1\~100까지 오르고, 레벨업마다 스탯 포인트, 5레벨마다 특성 포인트를 얻는다. 레벨은 죽어도 유지된다.

- **경험치**: 전투·채굴·제작·건축·마법 사용으로 얻는다. 얻은 경험치는 레벨에 누적되는 동시에 분야 포인트(공학·산업·마력학, 전투는 전투 경험치 CXP)로도 쌓여 연구에 쓸 수 있다(13장). 연구에 써도 레벨은 줄지 않는다.
- **필요 경험치**: 레벨 n → n+1 = 100 × 1.08ⁿ (레벨 10에 약 216, 50에 약 4,700, 99에 약 20만)
- **포인트 총량**: 스탯 99, 특성 20. 스탯 상한 합계가 130이라 모두 채울 수는 없다.

| 스탯 | 포인트당 효과 | 상한 |
| --- | --- | --- |
| 체력 | 최대 체력 +1 (20 → 40) | 20 |
| 마력 | 최대 마력 +4 (20 → 100) | 20 |
| 근력 | 근접 피해 +2% | 25 |
| 사격 | 총기 피해 +2%, 반동 −2% | 25 |
| 지구력 | 달리기 시간 +4%, 배고픔 소모 −2% | 15 |
| 통솔 | 지휘 범위 +2블록, 범위 내 병사 공격·방어 +1% | 25 |

| 특성 갈래 | 대표 특성 | 궁극 특성 (해당 갈래 5포인트 이상) |
| --- | --- | --- |
| 전사 | 강타(차지 피해 +30%), 패링 반격, 돌진 베기, 강철 피부(방어 +10%), 광전사(체력 30% 이하에서 공격 +25%) | 대지 가르기: 전방 부채꼴 범위 강타 |
| 사수 | 빠른 재장전, 약점 사격(치명타), 폭발물 전문가(범위 +20%), 반동 제어, 저격 호흡 | 탄막: 10초간 연사 속도 2배 |
| 마도 | 마력 효율(소모 −15%), 이중 시전, 각인 숙련(시간 −25%), 마력 흡수(처치 시 마력 회복), 결계 강화 | 과부하 시전: 주문 위력 ×2, 대신 체력 소모 |
| 통치자 | 카리스마(근처 주민 생산 +10%), 전장의 왕(사기 +), 명성(이주 매력도 +), 외교관, 병참(보급 소모 −) | 왕의 호령: 하루 1회, 영토 전체 30초 전투 버프 |

- 왕국 등급이 오를 때마다 왕에게 칭호가 붙는다(개척자 → 촌장 → … → 황제). 효과는 없고 상징용.
- 특성 초기화는 마석을 소모하는 의식으로 가능(비용 높음).

## 26. 마법 체계

주문은 마법진으로 만든 ‘주문 회로판’을 매체에 꽂고 마력을 써서 발동한다. 각인은 장비에 붙는 영구 효과, 주문은 필요할 때 쓰는 능동 기술이다.

1. **해금**: 기술 트리 마력학에서 주문을 연구한다.
2. **제작**: 회로 작업대에서 기판 금속 + 마석 분말로 주문 회로판을 만든다. 분말 등급이 주문 레벨(1\~5)을 정한다.
3. **장착**: 매체의 슬롯에 회로판을 꽂는다. 단축키로 전환하며 시전.

| 매체 | 특징 | 슬롯 |
| --- | --- | --- |
| 마력 건틀릿 | 보조 손에 착용, 무기와 함께 사용 | 재료 등급에 따라 1\~3 |
| 마도 지팡이 | 양손, 주문 위력 +30% | 2\~5 |
| 총기 마법진 모듈 | 총에 부착, 탄환에 주문 속성 부여 | 1 |

주문 피해 = 주문 기본값 × 매체 재료의 공격 배율 × 순도로, 무기와 같은 밸런스 체계(24장)를 따른다. 마력은 초당 1씩 자연 회복하고, 마력 배터리를 소모해 즉시 채울 수도 있다.

| 계열 | 주문 | 마력 | 효과 (레벨 1 기준) | 해금 시대 |
| --- | --- | --- | --- | --- |
| 원소 | 화염탄 | 4 | 단일 피해 9.6 + 화상 | 중세 |
| 원소 | 냉기 파동 | 6 | 원뿔 범위 피해 5 + 둔화 | 증기 |
| 원소 | 연쇄 번개 | 8 | 최대 4체 피해 7 | 산업 |
| 역장 | 밀쳐내기 | 3 | 주변 넉백 | 중세 |
| 역장 | 마력 방벽 | 6 | 전방 보호막, 피해 20 흡수 | 증기 |
| 역장 | 반중력 도약 | 4 | 높이 점프, 낙하 피해 무시 | 산업 |
| 강화 | 재생 | 6 | 10초간 체력 6 회복 | 중세 |
| 강화 | 가속 | 5 | 30초간 이동·공격 속도 +20% | 증기 |
| 강화 | 강철화 | 8 | 20초간 방어 +50% | 산업 |
| 탐지 | 야간 시야 | 2 | 2분간 어둠 제거 | 중세 |
| 탐지 | 광맥 감지 | 3 | 반경 32블록 광석 윤곽 표시 | 증기 |
| 탐지 | 적 감지 | 3 | 반경 48블록 적 표시 | 산업 |
| 공학 | 원격 가동 | 2 | 멀리 있는 마력 장치 켜기·끄기 | 증기 |
| 공학 | 원격 수리 | 5 | 기계·탈것 내구 회복 | 산업 |
| 의식 | 전장 결계 | 마력로 연결 | 반경 32블록 아군 방어 +30% | 근대 |
| 의식 | 마력 포격 | 마력로 연결 | 지정 지점 대폭발 | 근대 |

- 레벨이 하나 오를 때마다 위력 +25%, 마력 소모 +20%.
- **의식 주문**: 의식진 블록 + 마력로 + 마도사 여러 명이 필요하고, 준비 시간이 있다. 전쟁의 전략 무기.
- **주민 마도사**: 역할 세트(공격·지원·방어)를 받아 자동으로 시전한다.
- **부작용**: 주문을 많이 쓸수록 그 자리에 마력 오염이 쌓이고, 마력이 모자라는데 시전하면 체력으로 대신 치른다.

## 27. 기술 스택·에셋 제작

C++20 + OpenGL 4.5로 자체 엔진을 만들고, 모든 게임 데이터는 외부 파일로 분리한다. 세부 코드·파일 구조는 개발 단계에서 Claude Code가 정한다.

| 분야 | 선택 (제안) | 이유 |
| --- | --- | --- |
| 언어·빌드 | C++20, CMake | 요청 언어, 크로스플랫폼 |
| 창·입력 | GLFW | 가볍고 안정적 |
| 렌더러 | OpenGL 4.5 (후에 Vulkan 검토) | 개발 속도 우선 |
| 수학 | GLM | 표준 |
| 엔티티 | EnTT (ECS) | 수백\~수천 주민·병사 처리 |
| 지형 생성 | FastNoiseLite | 바이옴·광맥 노이즈 |
| 물리 | Jolt Physics (탈것만) | 차량·함선 강체 |
| 사운드 | miniaudio | 단일 헤더 |
| 데이터 | JSON (블록·아이템·레시피·연구·각인·합금) | 코드 수정 없이 밸런싱 |
| UI | 자체 게임 UI + Dear ImGui(개발·디버그 전용) | 게임 분위기 유지 |
| 저장 | 영역(region) 파일 + LZ4 압축 | 빠른 청크 입출력 |

**엔진 계층 (개요)**: 코어(스레드풀·이벤트·에셋) → 월드(청크·생성·메싱) → 렌더러 → 엔티티(ECS·애니메이션·물리) → 시뮬레이션(왕국·경제·AI) → 게임플레이·UI·명령어

**네트워크**: 서버가 월드·왕국·AI 상태의 권한을 갖고 클라이언트는 입력·렌더링만 맡는다. 싱글도 같은 구조(내장 서버). 통신은 ENet 또는 GameNetworkingSockets 검토, 틱 20/초.

**에셋 (내가 제작)**

- **텍스처**: 팔레트 + 노이즈 + 높이맵 음영 규칙으로 32×32 텍스처와 노멀·발광·재질 맵을 생성하는 스크립트를 만들고 PNG로 출력. 사람이 직접 고쳐 그린 PNG로 교체하는 것도 가능. 아틀라스는 자동 패킹.
- **모델**: 큐보이드 파트 JSON(Blockbench에서 열어 수정할 수 있는 형식을 목표)
- **애니메이션**: 키프레임 JSON + 코드로 짠 절차 레이어 (14장)
- **UI·아이콘·문장**: 텍스처와 같은 음영 규칙으로 생성, 한글은 오픈 라이선스(OFL) 폰트 사용
- **사운드**: 절차 생성 효과음 + CC0 자료. 후반 단계로 미룸
- 한계: 절차 생성 아트는 통일감은 좋지만, 최상급 디테일은 사람 손으로 다듬는 단계가 필요할 수 있다.

## 28. 단계별 개발 로드맵

**각 단계가 끝날 때마다 플레이 가능한 빌드가 나온다**

| 단계 | 이름 | 범위 | 완료 기준 |
| --- | --- | --- | --- |
| P0 | 엔진 기반 | 내장 서버 구조, 렌더러, 청크·월드·바이옴 생성, 블록 설치·파괴, 기본 쉐이더, 이동 | 렌더거리 16청크 60fps로 걷고 블록을 부수고 놓기 |
| P1 | 생존 코어 | 인벤토리·제작, 13종 자원, 제련·합금·순도, 기본 몬스터, 근접 전투 v1, 명령어, 저장 | 나무부터 강철 장비까지 혼자 생존 가능 |
| P2 | 왕국·주민 | 왕좌 선포·영토, 주민 AI·욕구 1~2단계, 직업·생산 체인, 청사진 건축, 정부 조직 | 주민 50명이 자급자족하는 촌락 유지 |
| P3 | 마력·각인·연구 | 마석 가공, 마법진·마력망, 마력 배터리, 각인 작업대, 기술 트리·교육 | 각인 도구로 생산량 증가, 배터리로 공장 가동 |
| P4 | 군사·외교 | 징집·부대·장군, 전술 연구, AI 왕국·외교·전쟁, 둥지·던전, 총기·폭발 | AI 왕국 하나를 전쟁으로 복속 |
| P5 | 탈것·산업 | 차량·선박·프롭기, 반중력 Lv1~2, 산업 로봇·철관 보행기, 욕구 3~5단계 | 트럭 보급선과 폭격기로 원정 승리 |
| P6 | 후반·완성 | 비행 전함·항모, 제트기, 특수 각인, 고급 쉐이더, 밸런스·최적화 | 아시리아 제국을 파괴·복속해 승리하는 한 판 완주 |

한 번에 만들지 않고 7단계로 나눈다. 멀티플레이는 P6 뒤 P7로 붙이되, 서버 구조는 P0부터 반영한다. 각 단계는 완료 기준을 통과해야 다음으로 넘어가며, 착수 전에 그 단계의 세부 설계(파일·클래스 구조, 데이터 형식)를 Claude Code가 먼저 작성한다. 에셋(텍스처·모델·애니메이션)은 해당 단계에 필요한 것만 함께 만든다.

## 29. 리스크·범위 관리

이 기획 전체는 상업 인디 팀 기준으로도 수년 규모다. 그래서 단계마다 플레이 가능한 빌드를 내고, 다음 단계로 넘어가기 전 기능을 동결하는 것을 원칙으로 한다.

| 리스크 | 영향 | 대응 |
| --- | --- | --- |
| 범위 과대 | 미완성으로 끝남 | 단계별 플레이 빌드, 단계별 기능 동결 |
| 성능 (복셀 + 주민 수백 + 군대) | 프레임 하락 | ECS, 틱 예산 분산, 원거리 추상 시뮬레이션(주민 1만 명 규모에서는 플레이어 근처 도시만 개체 단위, 나머지는 수치로 처리), 초기부터 프로파일러 |
| 대형 함선 물리 | 버그·개발 지연 | 1차는 부품 조합형 모델, 블록 제작 함선은 후속 |
| 아트 품질 | 시각적 매력 부족 | 절차 생성 + 사람이 교체 가능한 파이프라인 |
| 밸런스 (기하급수 배율) | 후반 장비가 모든 적을 압도 | 적·둥지·던전 난이도도 동일 곡선으로 스케일링, 수치는 데이터 파일로 분리 |
| 지식재산권 | 배포 불가 | 마인크래프트·워해머·Actions & Stuff의 에셋·명칭 미사용, 분위기만 참고 |
