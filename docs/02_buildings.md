# 건물 목록

모든 건물은 기본 디자인으로 지어지고, 플레이어가 꾸미거나 구조를 바꿀 수 있다(본문 8장 건축). 표의 ‘최소 크기’와 기능 블록이 필수 조건이고, ‘비용’은 기본 디자인 기준 초안이다. 건물을 넓히면 기능 블록을 더 놓을 수 있고, 그만큼 작업자·거주자가 늘어난다(상한 = 기본의 3배).
